# 44 · 后台运行与贸贸悬浮窗

目标版本 **0.6.6** · Windows 桌面端 · 需求稿，2026-11-28。[GitHub Issue #175](https://github.com/Pedro-MAFS/ftcs/issues/175)

[后台运行与贸贸悬浮窗详细设计](design/US-BG-01至03-后台运行与贸贸悬浮窗.md)

## 用户目标

用户关掉 FTCS 主窗口时，能决定让应用继续运行还是完全退出。选择后台运行后，即使系统托盘图标被 Windows 折叠，用户也能从桌面上的贸贸看出 FTCS 仍在运行，随时回到刚才的工作区。已经习惯只用托盘的用户可以继续安静地使用。

## US-BG-01 · 关窗时选择去向

当关窗偏好为「每次询问」时，用户点击主窗口的 ×（或按 Alt+F4），显示以下对话框。重复关窗只保留一个对话框。

> **关闭 FTCS 后，是否继续在后台运行？**  
> 后台运行时，邮箱会继续同步，定时任务会按计划执行。  
> □ 记住我的选择  
> **后台运行**　 **退出 FTCS**

- **后台运行**隐藏主窗口，系统托盘继续提供入口。当前工作区、打开的标签和已有任务留在原处。
- **退出 FTCS**走完整退出流程。邮箱草稿保存失败时，留在主窗口，提示用户处理后再退出。
- 「记住我的选择」默认未勾选。勾选并确认后，后续关窗直接执行所选动作，重启后仍有效。未勾选只影响本次，下次关窗再问。按 Esc 或关闭对话框会取消本次操作，主窗口及偏好保持原状。
- 「设置 → 启动与托盘 → 关闭窗口行为」提供 **每次询问 / 后台运行 / 退出 FTCS**。用户可随时修改，也可恢复为每次询问。偏好属于本机应用，切换产品或工作区时沿用。

## US-BG-02 · 通过贸贸查看后台状态、回到工作区

设置中提供独立开关「主窗口最小化或隐藏时显示贸贸」。主窗口最小化或隐藏时默认显示贸贸，包括旧版托盘用户升级和登录自启。已有显示偏好时沿用保存的值。

| 用户动作或场景 | 可观察的结果 |
| --- | --- |
| 主窗口已最小化或隐藏，且开启显示贸贸 | 桌面出现一个透明背景的贸贸，微笑出场，半秒后连续眨两下眼；空闲时每隔 4～8 秒眨眼，偶尔双眨。空闲时也显示，表示 FTCS 进程仍在运行。 |
| 鼠标悬停 | 贸贸朝鼠标靠近的一侧轻轻歪头、张嘴笑，移开后恢复微笑。按住拖动时保持原大小和正立姿态。 |
| 单击贸贸 | 恢复原主窗口和当前标签，贸贸收起。通过托盘恢复或从新邮件通知进入会话时也收起贸贸。 |
| 拖动贸贸 | 可以移动到桌面上的其他位置或显示器，在同一屏幕上移动时保持大小，松手后停在该处。拖动不会触发打开工作区。 |
| 右键贸贸 | 菜单提供「打开工作区」「隐藏贸贸」「退出 FTCS」。 |
| 选择「隐藏贸贸」 | 收起悬浮窗并关闭显示偏好。后续后台运行只显示托盘；从托盘恢复主窗口后，可在设置中重新开启。 |
| 从贸贸或托盘选择「退出 FTCS」 | 直接执行退出流程。成功后主窗口、贸贸和托盘图标一并消失，邮箱同步和定时调度停止。 |
| 主窗口失焦或普通最小化 | 单纯切换焦点时保持原状。最小化后按开关显示贸贸；点击任务栏图标或贸贸都可还原主窗口并收起悬浮窗。 |

使用现有的微笑、眨眼和张嘴三帧。开启系统「减少动态效果」时，悬停只切换笑脸，平时保持微笑。素材见[贸贸形象与动画帧说明](../ftcs-mascot-icons/README.md)。

## US-BG-03 · 升级与旧版后台入口兼容

旧版「关闭窗口时最小化到托盘」使用布尔偏好 `closeToTrayEnabled`。保存其他设置也可能写入默认值 `false`，因此无法凭这个值判断用户是否主动选择过退出。首次读取新版偏好时，按下表处理。

| 首次使用新版时的情况 | 关窗行为 | 贸贸显示 |
| --- | --- | --- |
| 新安装，或旧值缺失、为 `false` | 每次询问 | 进入后台时默认显示 |
| 旧值为 `true`，含通过定时任务一键开启的用户 | 直接进入后台 | 默认显示，用户可以自行隐藏 |
| 已经有新版偏好 | 使用新版选择 | 使用已保存的显示偏好 |

保存模型、邮箱等无关设置时，关窗行为和贸贸开关应保留原值。新版本也保留以下入口，详见[原定时编排、托盘与开机自启需求](23-需求-定时编排托盘与开机自启.md)。

- **定时任务**：用户在定时页主动「一键开启」时，启用开机自启，并将关窗行为设为「后台运行」。已有的贸贸显示选择继续生效。仅保存定时任务不会代替用户修改这两项启动设置。
- **开机自启**：登录 Windows 后静默进入后台，主窗口不抢焦点，也不弹关窗询问。默认显示贸贸，已关闭显示时仅保留托盘入口。
- **后台工作**：关窗进入后台、隐藏贸贸、恢复主窗口都不重启后台服务。已连接邮箱继续同步，已启用的定时任务沿用原调度规则，正在运行的本地站点预览继续可用。

## 验收场景

| 编号 | 操作 | 预期结果 |
| --- | --- | --- |
| 1 | 新安装后首次点 ×，先按 Esc，再点 × 选择「后台运行」，不勾选记住 | 第一次取消后仍在原页面；第二次主窗隐藏，出现贸贸。单击恢复，再关窗仍会询问。 |
| 2 | 分别勾选记住「后台运行」和「退出 FTCS」，重启后再次关窗 | 各自直接执行所选动作。在设置中改回「每次询问」，下次关窗重新弹框。 |
| 3 | 分别用缺少旧字段、旧值为 `false`、旧值为 `true` 的配置升级，再保存一次无关设置 | 前两组首次关窗会询问；第三组直接进入后台。三组在后台均默认显示贸贸。 |
| 4 | 在编辑中的工作区切到其他应用、最小化，再还原并关窗进入后台；拖动、单击贸贸 | 最小化和关窗进入后台均显示贸贸，还原后收起，单纯失焦时保持原状。拖动只移动悬浮窗，单击回到原标签和编辑现场。 |
| 5 | 隐藏贸贸，等待测试邮件或已安排的定时任务，再通过托盘回到工作区 | 托盘可用，邮件正常同步或任务按计划执行。再进后台仍只显示托盘；开启显示开关后再进后台可见贸贸。 |
| 6 | 在定时页一键开启后台运行，分别以贸贸开、关两种偏好验证 Windows 登录自启 | 主窗口保持隐藏，无关窗弹框。贸贸显隐符合偏好，恢复工作区后可看到原定时方案。 |
| 7 | 编辑一份邮箱草稿，分别从贸贸和托盘点「退出 FTCS」 | 不再弹关窗选择框。正常退出后重新打开能恢复草稿；模拟保存失败时主窗可见，可处理草稿并重新退出。 |
