## 1. 目的与边界

本文档只描述 **桌面端搜索如何随「官方 / 自定义」模型通道切换**，以及官方通道下如何调用网关搜索 API。

| 在本文档 | 不在本文档 |
|----------|------------|
| 设置页搜索 Key 置灰 / 自备逻辑 | 网关按次价目、结算、表结构 |
| MCP `search-api` 改打网关或继续直连 Tavily | Tavily 上游错误内部映射细节 |
| 与官方模型 `sk-` / baseURL 复用 | 网关实现与单测 |

**实现顺序**：网关 G5 阶段 C 出门（或契约冻结）后再改桌面。

---

## 2. 已拍板 UX（2026-08-07）

| 模型通道 | 搜索 API Key（设置页） | 实际调用 |
|----------|------------------------|----------|
| **官方通道** | **置灰**；自动视为与模型相同的官方网关 `sk-`（展示可掩码/说明「与官方模型凭证相同」，**不必**再让用户粘贴 Tavily Key） | MCP → **Token 网关** `POST /v1/search` + `Authorization: Bearer sk-…` |
| **自定义通道** | **可编辑**；用户自备 Tavily Key（现网行为） | MCP → **直连** `https://api.tavily.com/search`（BYOK，不经网关、不扣官方余额） |

说明：

- 「自动填上跟模型一样的」= 官方通道下搜索鉴权复用已写入的官方 `sk-` / 网关 baseURL，**不是**把 Tavily 官网 Key 填进输入框。  
- 从官方切回自定义时：恢复 Tavily Key 输入；若本地无 Key 则沿用现有预检/引导。  
- 本地 `SEARCH_DAILY_LIMIT`：自定义通道可保留；官方通道以**账户余额预检**为准（是否仍保留本地日限额作双保险，实现时定，默认官方通道可放宽或取消本地限额以免与余额双重拒绝）。

## 3. 成功标准（桌面侧）

| 编号 | 标准 |
|------|------|
| S-SEARCH-1 | 仅配置官方模型通道（已有网关 sk）即可完成依赖 `search_web` 的探索主路径，**无需**用户配置 Tavily Key |
| S-SEARCH-2 | 自定义通道 + 自备 Tavily Key 行为与现网一致（不走网关计费） |
| S-SEARCH-3 | 官方通道下设置页搜索 Key 控件置灰且文案不引导去 Tavily 注册（或弱化） |

网关侧按次扣费验收见 token-gateway `docs/15` 阶段 E。

---

## 4. 对接架构

```
官方通道:
  设置: model=官方 → 注入 GATEWAY_BASE_URL + sk-
  MCP search-api → POST {gateway}/v1/search  (Bearer sk-)
                 → 网关持有 TAVILY_API_KEY → Tavily
                 → 按次扣官方余额

自定义通道:
  设置: 用户填写 TAVILY_API_KEY
  MCP search-api → POST https://api.tavily.com/search  (现网)
```

## 6. 与网关契约（消费方视角）

| 项 | 约定 |
|----|------|
| 方法/路径 | `POST /v1/search`（契约见 [US-G5-01](../token-gateway/docs/design/US-G5-01-Tavily搜索代理设计.md)） |
| 鉴权 | `Authorization: Bearer sk-…`（与 Chat 同一把官方 Key，如 `name=ftcs-desktop`） |
| 请求要点 | `query` 必填；`max_results` 1～10（对应工具 `num_results`）；仅 `search_depth=basic`。站点收窄与直连 Tavily 相同：**有** `include_domains` 时原样转发（R2），**没有**时转发固定 `exclude_domains`（R1，Facebook / Google 等）。两种不要同时传。**不要**传 `num_results` / `api_key` / `include_answer` / `include_raw_content`。网关须把 `include_domains` / `exclude_domains` 原样转给 Tavily，否则官方 R1 排除与官方 R2 限定都不能点收 |
| 响应要点 | `results[]`：`title` / `url` / `content` / 可选 `score`；MCP 可继续走现有 `mapTavilyResults` |
| 计费 | 用户侧感知为扣官方余额；单价见面板价格或文档；桌面不展示厘 |
| 失败 | 402/401 需可映射为设置页/预检可理解提示 |

字段级 schema 以网关 US-G5-01 详设为准；本分册不复制价目公式。
