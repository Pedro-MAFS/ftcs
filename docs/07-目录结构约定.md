# 07 - 目录结构约定

本文档定义仓库目录布局。所有模块、Skills、MCP 服务必须遵守此约定，确保跨环境与跨阶段一致。

## 1. 仓库根目录

```
foreign-trade-customer-search/
├── README.md
├── .gitignore
├── .env.example
├── .cursor/
│   ├── mcp.json              # Cursor MCP 配置（Phase 1）
│   └── skills/               # Cursor Skills（从 skills/ 同步）
├── docs/                     # 项目文档
├── config/                   # 全局配置
├── data/                     # 运行时数据（部分 gitignore）
├── skills/                   # Agent Skills 源文件
├── mcp-servers/              # MCP 服务实现
├── scripts/                  # 工具脚本
├── desktop/                  # Electron 桌面应用（Phase 2）
│   ├── electron/             # 主进程、预加载、OpenCode SDK Runtime
│   ├── src/                  # Vue3 渲染进程
│   └── resources/            # 预留 bundled opencode CLI（当前未用）
└── logs/                     # 运行日志（gitignore）
```

## 4. data/

```
data/
├── products/
│   └── {product_id}/
│       ├── profile.json      # 产品画像
│       └── inputs/           # 用户上传的原始文件
│           ├── catalog.pdf
│           └── price-list.xlsx
├── keywords/
│   └── {product_id}/
│       └── expansion.json    # 关键词扩展结果
├── leads/
│   └── {product_id}/
│       ├── raw/              # 原始线索（按轮次）
│       │   ├── R1.jsonl
│       │   └── R2.jsonl
│       └── scored.json       # 评分去重后的线索
├── emails/
│   └── {lead_id}/
│       ├── draft.json        # 邮件草稿（结构化）
│       └── draft.md          # 邮件草稿（人类可读）
├── exploration/
│   └── {product_id}/
│       └── runs/
│           └── {run_id}.json # 探索运行记录
└── cache/                    # API 缓存（可选）
    └── search/
        └── {hash}.json
```

### 特殊目录

| 路径 | 说明 |
|------|------|
| `data/products/_example/` | 示例数据，纳入 Git，供参考 |
| `data/products/{real_id}/` | 真实业务数据，不纳入 Git |
| `data/cache/` | 缓存，不纳入 Git |

## 11. 命名规范

| 类型 | 规范 | 示例 |
|------|------|------|
| 产品 ID | `prod_{YYYYMMDD}_{seq}` | `prod_20260709_001` |
| 线索 ID | `lead_{YYYYMMDD}_{seq}` | `lead_20260709_0001` |
| 探索运行 ID | `run_{YYYYMMDD}_{seq}` | `run_20260709_001` |
| Skill 目录 | kebab-case | `extract-product-profile` |
| MCP 服务 | kebab-case | `lead-store` |
| 配置文件 | kebab-case.yaml | `scoring-rules.yaml` |

## 12. 初始化命令

**Linux / macOS**：

```bash
mkdir -p data/products/_example/inputs \
         data/keywords data/leads data/emails data/exploration data/cache/search \
         config skills mcp-servers scripts logs/exploration \
         .cursor/skills docs/retrospective
```

**Windows PowerShell**：

```powershell
$dirs = @(
  "data/products/_example/inputs",
  "data/keywords", "data/leads", "data/emails",
  "data/exploration", "data/cache/search",
  "config", "skills", "mcp-servers", "scripts",
  "logs/exploration", ".cursor/skills", "docs/retrospective"
)
$dirs | ForEach-Object { New-Item -ItemType Directory -Force -Path $_ }
```
