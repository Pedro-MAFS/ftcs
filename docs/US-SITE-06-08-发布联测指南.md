# 独立站发布联测指南

本指南验证 FTCS 将工作区站点源码提交到用户自己的 GitHub 仓库，并通过 Cloudflare Pages Git 集成构建与部署。GitHub 和 Cloudflare 的真实写入接口、授权范围及首次部署行为需要通过本次联测确认。

## 准备

1. 在测试工作区创建独立站，确认本地预览和构建检查可用。站点位于当前工作区的 `website/`，默认模板产物目录为 `dist`。
2. 连接 GitHub 和 Cloudflare，并在 FTCS 选择目标 Cloudflare 账号。GitHub 上的 FTCS App 需要获准访问目标仓库，并具备仓库内容写入权限。
3. 准备专用测试仓库及 Pages 项目名。可在 FTCS 尝试创建 GitHub 个人仓库；也可在 GitHub 手动创建并初始化 README，再在 FTCS 勾选允许替换或删除该 README。不要使用存放其他资料的仓库。
4. Cloudflare 对 GitHub 的仓库访问授权与 FTCS GitHub App 授权是两回事。如果 Cloudflare 要求授权，需要在 Cloudflare/GitHub 官方页面单独完成。

## 首次发布

1. 点击「发布网站」，选择测试仓库和生产分支。核对仓库归属、公开或私有状态以及写入权限；网站部署成功后，即使仓库私有，网站仍可能公开访问。
2. 点击「检查源码并构建」。FTCS 会冻结源码，在临时目录用 FTCS 的 Node/npm 安装依赖并执行构建脚本；期间可以取消。请核对构建是否成功，以及原始 `website/` 目录是否仍完整。
3. 展开源码清单，点击文本文件查看本次快照内容，检查没有不应公开的文件。`.git/`、`node_modules/`、产物目录、`.env`、`.npmrc` 和常见证书私钥文件不会上传；普通源码仍可能包含敏感信息，需要用户自行核对。
4. 确认仓库、分支、文件变化后点击「确认推送到 GitHub」。推送成功后，到 GitHub 核对源码、提交版本及文件内容。此时 FTCS 只应显示「已推送」，不能宣称网站已上线。
5. 点击「创建 Pages 项目」，确认项目名、仓库、分支、`npm run build`、产物目录及 Node 版本（默认模板建议 24），然后确认创建。Cloudflare 可能立即开始部署。若提示需要授权或创建结果待确认，先在 Cloudflare 控制台检查；不要反复创建同名项目。
6. 若自动创建或 GitHub 关联不可用，在 Cloudflare 官方页面完成 GitHub 授权并创建 Git 集成 Pages 项目，再回到 FTCS 刷新并选择该项目。项目的仓库、生产分支、构建命令、根目录和产物目录必须与 FTCS 目标匹配。不要选择 Direct Upload 项目。
7. 等待并刷新部署状态。FTCS 只在查到本次提交对应的生产部署成功时显示成功；打开 `pages.dev` 地址，核对页面内容。若一直等待，查看 Cloudflare 是否实际发起首次部署及其构建日志，记录结果。

## 再次发布与恢复

1. 修改站点页面并预览，重新发布；核对差异清单、新的 GitHub 提交及 Cloudflare 部署。等待新版本成功前，旧网站仍可能可访问。
2. 源码没有变化时不应创建空提交。若云端构建失败，应显示失败，并保留最近一次确认上线的版本信息。
3. 在 GitHub 上手动改动生产分支后再发布，FTCS 应阻止覆盖并提示先协调远端内容。
4. 如提交或项目创建请求中断，重启 FTCS 后应看到待确认状态；先检查 GitHub 或 Cloudflare 的实际结果，再选择恢复或清除待检查状态。
5. 尝试取消一次较慢的构建检查，确认没有执行 GitHub 推送。切换工作区时，应先停止本地构建；正在进行的远端操作需要等待或恢复。

## 当前范围

- 默认模板及普通纯前端 Node 站点需要提供 `npm run build`；项目自行配置实际静态产物目录。云端使用 Cloudflare 的 Node，而非用户本地 Node 路径。
- 单个源码文件上限为 8 MB，整个快照上限为 20 MB、3,000 个文件；暂不支持 Git LFS、子模块、符号链接和可执行权限文件。
- 不自动上传本地 `.env`、`.npmrc` 或 FTCS 凭据；站点构建所需敏感环境变量需在 Cloudflare 安全配置中设置。
- 首次使用 `pages.dev` 地址时，模板可能尚未配置 `SITE_URL`，因此 sitemap 需要后续配置地址并重新部署。自有域名和站内询盘接收属于后续需求。

请记录测试系统、点击的步骤、界面提示、GitHub 提交及 Cloudflare 项目/部署状态；请勿发送访问令牌、密钥或 `.env` 内容。
