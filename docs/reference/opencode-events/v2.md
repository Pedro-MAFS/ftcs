# V2 信封格式

> **订阅**：`GET /api/event` · SDK `client.v2.event.subscribe()`  
> **TS 类型**：`V2Event`（`MessagePartUpdated` 等，无 `Event` 前缀）  
> **总览**：[README](./README.md) · **嵌套类型**：[nested-types.md](./nested-types.md) · **何时触发**：[triggers.md](./triggers.md)

---

## 1. 根 JSON 结构

每条 SSE 消息 **就是** 一个 V2 事件对象：

```typescript
interface V2Envelope {
  id: string
  type: string
  metadata?: Record<string, unknown>
  durable?: {
    aggregateID: string
    seq: number
    version: number
  }
  location?: LocationRef
  data: {                    // 载荷（Legacy 里叫 properties）
    [key: string]: unknown
  }
}
```

### 识别条件

- 根上有 `type` + **`data`**
- 根上 **没有** `properties`（那是 Legacy）
- 根上 **没有** `directory`（那是 Global 外包）

### 示例

```jsonc
{
  "id": "evt-001",
  "type": "session.next.text.delta",
  "metadata": {},
  "durable": {
    "aggregateID": "agg-xyz",
    "seq": 12,
    "version": 1
  },
  "data": {
    "timestamp": 1710000000000,
    "sessionID": "ses-abc",
    "assistantMessageID": "msg-1",
    "textID": "txt-1",
    "delta": "Hello"
  }
}
```

## 2. 与 Legacy 的对应关系

| 项目 | Legacy | V2 |
|------|--------|-----|
| 载荷键名 | `properties` | `data` |
| `type` 字符串 | 相同 | 相同 |
| 载荷字段 | 相同 | 相同 |
| 额外根字段 | 无 | `metadata?`, `durable?`, `location?` |
| SDK 类型前缀 | `Event*` | 无 `Event` 前缀 |

**语义以 `type` 为准**；读 V2 时把 `data` 当作 Legacy 的 `properties` 即可。

- 示例：`MessagePartUpdated` → `type: "message.part.updated"`

## 5. V2 独有根字段说明

| 字段 | 含义 |
|------|------|
| `metadata` | 事件元数据，开放键值 |
| `durable` | 持久化事件序号，用于同步/回放 |
| `location` | 工作区位置引用 |

---

## 6. 完整 type 列表

与 SDK `export type V2Event = …` 一致；**不包含** Sync 专有的 `type: "sync"` 包装，也不包含 `.1` 后缀 type（见 [sync.md](./sync.md)）。

字段定义：**一律查 [legacy.md](./legacy.md) 同名 type，把 `properties` 换读为 `data`。**
