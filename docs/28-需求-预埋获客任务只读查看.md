## 1. 一句话目标

用户在任务列表点开预埋的 **标准获客**、**高级获客** 时，能看到与现网**方案编辑页同构、但全只读**的详情，从而知道该任务实际跑哪些步骤；仍不可改、不可删。

---

## 2. 背景与动机

| 现象 | 痛点 |
|------|------|
| 内置「标准获客 / 高级获客」不可编辑 | 现网 ⋯ 菜单「编辑 / 删除」对内置 disabled，**也没有查看入口** |
| 用户只见方案名，不知步骤链 | 不利于理解与信任「点执行会干什么」 |
| 自定义方案已有编辑弹框 | 不必另做一套信息架构；应复用同构 UI 的只读态 |

马丰顺 2026-10-03 / 10-04 确认：

- 列表点开 → **只读详情**；仍不可编辑。  
- **不**做「复制为模板」。  
- **不**改预埋任务业务逻辑 / 步骤定义。  
- 展示粒度：**尽量贴近现网编辑页，只是全只读**。

## 3. 已确认产品规则

| # | 规则 |
|---|------|
| **PV1** | **对象**：仅预埋内置方案 **`builtin-standard`（标准获客）** 与 **`builtin-advanced`（高级获客）**。 |
| **PV2** | **入口**：在**任务列表 / 方案区**（现网为线索页 `WorkflowPlanControl` 一带）可**点开**进入只读详情；内置方案必须有明确「查看」路径（不得继续只有 disabled 无替代）。形态交详设（例如：选中内置后 ⋯ 菜单「查看方案…」、或点开名称等价入口），须可发现、可键盘/鼠标到达。 |
| **PV3** | **展示同构编辑页**：只读详情在信息结构与布局上**尽量贴近**现网 `WorkflowPlanEditorDialog`（标题区 + **方案名称** + **有序步骤列表**）；步骤展示为节点**展示名**（与 §4 / `WORKFLOW_NODE_OPTIONS` 一致），顺序与预置定义一致。 |
| **PV4** | **全只读**：名称、步骤均不可改；无「添加 / 删除 / 上移 / 下移」可用操作；无「保存」。关闭用「关闭」或等价（取消/Esc/点遮罩），**不**写入磁盘。 |
| **PV5** | **不可编辑 / 不可删**：内置方案仍不可保存修改、不可删除；不得借只读入口绕过。 |
| **PV6** | **自定义方案不变**：用户自建方案的新建 / 编辑 / 删除行为与现网一致；本需求不改其编辑页能力。 |
| **PV7** | **不复制为模板**：本期不提供「复制为可编辑副本 / 另存为模板」。若以后需要另开 Issue。 |
| **PV8** | **不改预置逻辑**：不改 `builtin-standard` / `builtin-advanced` 的步骤内容、执行器映射、Preflight 或顺序执行行为。 |
| **PV9** | **版本**：纳入 **v0.5.8**；需求 PR 基线 **`dev-0.5.8`**。不因此关 #42；不合 `main`（发版时整支 `dev` 再合）。 |

## 4. 范围与非范围

### 4.1 本期做（In Scope）

1. 为 **标准获客、高级获客** 提供可点开的**只读详情**（同构现网编辑弹框信息结构）。  
2. 详情至少展示：**方案名称** + **有序步骤列表**（节点展示名，顺序正确）。  
3. 只读态下无编辑控件生效；关闭不落盘。  
4. 自定义方案 CRUD **行为保持**；内置仍不可删、不可改。

### 4.2 本期不做（Out of Scope）

| 项 | 说明 |
|----|------|
| 开放内置方案编辑 / 删除 | PV5 |
| 「复制为模板 / 另存为自定义」 | PV7 |
| 改预置步骤定义或执行逻辑 | PV8 |
| 独立「技能/工具清单」页、运行日志、历史执行回放 | 超出「贴近编辑页」；未确认 |
| 探索页任务入口统一（US-W-07） | 若探索页尚无同一方案控件，本期不强制挂查看；详设可注明「有控件的页面挂同一入口」 |
| 定时方案、通知文案改版 | 非本 Issue |
| 合入 `main` / 打 tag / 发版 | PV9；发版流程另走 |

### 4.3 预置步骤基线（只读须与之一致；不在本需求修改）

摘自 [docs/18](18-需求-任务编排一键跑通.md) §5（若仓库预置与此不一致，**以代码内置定义为准**，本需求只要求「只读展示与现网实际执行定义一致」）：

### US-PV-01　预埋标准/高级获客只读详情

**作为** 外贸业务员，**我想** 在任务列表点开「标准获客」或「高级获客」时看到和编辑页一样清楚的步骤说明（但不能改），**以便** 知道点「执行」会按什么顺序跑什么。

| 项 | 内容 |
|----|------|
| 优先级 | Must |
| 依赖 | 现网方案列表与 `WorkflowPlanEditorDialog` 信息结构 |
| 状态 | **待详设** |

**验收要点**

- 选中 **标准获客** 或 **高级获客** 时，存在可发现的入口打开只读详情（PV2）。  
- 只读详情展示 **名称** 与 **有序步骤**（节点展示名），布局/信息结构贴近现网编辑弹框（PV3）。  
- 标准获客、高级获客各自步骤顺序与现网预置定义一致（§4.3 / 代码内置）。  
- 详情内无法改名称、无法改步骤、无法保存；关闭不写 `workflow-plans.json`（PV4）。  
- 内置方案仍不可删除、不可通过本入口变成可编辑（PV5）。  
- 用户自定义方案的新建/编辑/删除仍可用，行为与现网一致（PV6）。  
- 无「复制为模板」入口（PV7）。  
- 不改变预置方案执行内容（PV8）。

**本故事不做**：探索页强制挂载（若该页尚无方案控件）；复制为模板；改预置定义。
