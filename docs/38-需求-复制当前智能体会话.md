# 38 - 需求：复制当前智能体会话

> **文档类型**：本期需求 + 用户故事（**US-CS**，Copy Session / 复制当前会话）  
> **状态**：**待详设**  
> **基线**：桌面端 **`dev-0.6.1`**  
> **对齐**：GitHub Issue [#117](https://github.com/Pedro-MAFS/ftcs/issues/117)；Milestone **v0.6.1**（Issue 正文写「规划中 / 暂不挂里程碑」，仓库里程碑已挂 **v0.6.1**，本文以该里程碑与本期版本为准）

## 1. 一句话目标

在智能体栏提供「复制当前会话」，一次把当前整段对话交给用户（未超限时进剪贴板，超限时存成下载目录里的文本文件），并带上排查用的版本号、时间等元信息，方便用户把现场交给开发。

---

## 2. 背景与动机

### 2.1 产品结论

马丰顺 2026-10-30：左侧智能体栏增加复制当前智能体会话，后续遇到问题方便用户提交反馈。纳入 **v0.6.1**，测分支 **`dev-0.6.1`**。

一次复制整段对话。内容格式便于排查，能带的上下文尽量带全。具体元信息字段由详设定。不超过长度上限时只进剪贴板；超过上限时，脱敏后全文改存系统下载目录。不自动上报。见 CS6 与 §7 O3。

### 2.2 现网路径（对照 `dev-0.6.1`）

| 环节 | 现网 |
|------|------|
| 智能体栏位置 | `WorkspaceLayout.vue` 从左到右是活动栏、产品与流水线侧栏、主区域、`AgentPanel`。智能体栏画在主区域右侧（`border-left`，宽 `--agent-width: 340px`）。Issue 称「左侧智能体栏」。`docs/design/Agent聊天框-Legacy-SSE时间线.md` 称「右侧 Agent 聊天框」。本期在现网这面栏上加入口，不搬动栏的左右位置。 |
| 栏内结构 | 标题「智能体」+ 当前技能名；其下是元信息卡片（如状态、产品、耗时，随任务种类变化）；中间是时间线；有等待回复时在时间线下方显示提问卡片；底部是输入框。输入框占位为「自由对话暂未开放，请用左侧流水线启动任务…」。点「发送」只提示暂不支持自由发送，不产生新的用户消息。 |
| 时间线条目 | `AgentTimelineItem.kind`：`user`（你）、`system`（系统）、`assistant`（回复）、`reasoning`（思考）、`tool`（工具）、`error`（错误）。子代理另有步骤列表（工具 / 思考 / 错误）。界面顺序即 `agentTimeline` 的数组顺序。 |
| 折叠与摘要 | 用户消息、思考，以及标记为折叠的条目，默认只显示正文前 160 字加省略号，需点「展开全文」才看到该条目持有的全文。子代理步骤默认收起，展开后长正文再按 80 字预览。 |
| 数据从哪来 | 时间线由主进程经 Agent 事件推到界面，存在进程内的 `agentTimeline`。设计说明写明每次流水线任务新建 session，内存即该次全集，没有「加载更早记录」。[docs/31](31-需求-探索等待用户回复.md) 写明该时间线无磁盘持久化，重启后即丢。新任务开始时 `resetTimelineView()` 清空时间线。 |
| 现成的复制 | 诊断详情、线索 JSON、分享下载链接各自有复制。智能体栏没有「复制当前会话」。 |
| 应用版本 | 桌面端 `package.json` 的 `version` 在编写本文时为 `0.6.0`。运行中的版本以应用自身版本为准（现网更新检查读取 `app.getVersion()`）。复制文本里的版本号取运行中的版本，不把本文编写时的号码写死。 |

### 2.3 痛点

| 现象 | 痛点 |
|------|------|
| 智能体栏没有复制入口 | 用户要反馈问题时，只能手选、截图或复述，对话容易缺段 |
| 时间线含工具调用与结果 | 手选容易漏掉折叠的正文、子代理步骤和报错 |
| 反馈里常常没有版本和时间 | 开发无法对照是哪一次运行、哪一个构建 |
| 若做成自动上传 | 超出「用户自己复制再提交」的范围，也带上未澄清的敏感信息问题 |

## 3. 已确认产品规则

> 取自 Issue #117 的目标、范围与验收草案。入口形态、脱敏见 §7，不在本表里补决定。超长会话（O3）已于 2026-11-01 锁定，见 CS6。

| # | 规则 |
|---|------|
| **CS1** | **入口在智能体栏**。提供「复制当前会话」。Issue 称该栏为「左侧智能体栏」。控件是顶部按钮还是菜单项，见 §7 O1。本期不改变智能体栏相对主区域的左右位置。 |
| **CS2** | **一次复制当前整段会话**。点击时带走当时智能体栏里的这一段对话，顺序与界面时间线一致。必须包含用户消息、智能体回复、工具调用及结果。不要求任务已经结束：栏里正在增长的时间线，按点击瞬间已有的条目复制。不超过 CS6 的长度上限时，这份全文进入剪贴板。超过上限时，全文在下载目录的文件里，剪贴板不承载正文，见 CS6。 |
| **CS3** | **空会话要提示，且不把占位句当对话**。时间线没有条目时，给出明确提示，不把「点击生成画像后…」这类空态说明写进剪贴板冒充会话。提示文案由详设定。 |
| **CS4** | **复制成功有明确提示**。未超限时，用户能看出全文已经进了剪贴板；该提示的具体文案与停留方式由详设定。超过 CS6 上限时，Toast 给出所存文件的完整路径，不再使用「已复制（内容过长已截断）」。 |
| **CS5** | **附带排查元信息，格式可读**。同一次复制的文本里包含应用版本号和复制时间。会话 / 任务标识、模型或服务状态、报错信息等其余字段，从 Issue 的举例里由详设取舍并给出样例，见 §7。版本号用运行中的应用版本。元信息放在正文之前还是之后，由详设定。 |
| **CS6** | **不自动上报。未超限只进剪贴板；超限改存系统下载目录。** 不上传服务器。用户如何把文本或文件交给开发（粘贴到聊天、邮件或 Issue，或自行发送该文件）不在本期。长度按脱敏后的全文计，上限 **200_000**。不超过上限：只把脱敏后全文写入剪贴板，不另存文件。超过上限：不把截断后的长文写入剪贴板，也不弹出另存为。脱敏后全文自动保存到系统下载目录（当前用户的下载文件夹），扩展名 `.txt`，文件名 `ftcs-session-YYYYMMDD-HHmmss.txt`（保存当时的本地时间，年月日-时分秒；项目经理已定）。Toast 给出该文件的完整路径，且与剪贴板中的路径相同。剪贴板只放一行「会话过长，全文已保存到：」紧接该完整路径，不放截断全文。脱敏规则本身仍见 §7 O2，本条不另定算法。 |
| **CS7** | **不改变会话的存储与展示**。不新增应用内的会话磁盘存储，不恢复重启前或上一次任务已经清掉的时间线，不改时间线的种类、顺序、折叠规则和任务推送方式。复制只读取当前栏里已有的内容。超过上限时按 CS6 把当次全文写到系统下载目录；该文件不是会话存储，不用于重启后找回时间线。 |
| **CS8** | **版本与关联**。纳入 **v0.6.1**。需求 PR 基线 **`dev-0.6.1`**，发版前不合 `main`。关联写法为 Related #117，**不关** Issue #117。 |

## 4. 范围与非范围

### 4.1 本期做（In Scope）

1. 智能体栏增加复制当前会话的入口（CS1）。  
2. 不超过 200_000 时，把当前整段对话按界面顺序写入剪贴板（脱敏后全文），覆盖用户消息、智能体回复、工具调用及结果（CS2、CS3、CS6）。  
3. 复制成功有提示；没有会话条目时有提示（CS3、CS4）。  
4. 同一份文本带上版本号、复制时间，以及详设写明的其他排查字段（CS5）。未超限时这份文本在剪贴板；超限时在下载的全文里。  
5. 复制失败或为空时，不改动时间线本身（CS7）。  
6. 超过 200_000 时，脱敏后全文自动保存到系统下载目录，文件名 `ftcs-session-YYYYMMDD-HHmmss.txt`；Toast 给出完整路径；剪贴板只放一行路径提示（CS6）。

### 4.2 本期不做（Out of Scope）

| 项 | 说明 |
|----|------|
| 自动上报或上传服务器 | CS6；Issue #117 范围外 |
| 改变会话存储、时间线展示、折叠与推送 | CS7 |
| 历史会话列表，或重启后找回已不在栏里的对话 | CS7；现网时间线只在进程内存中 |
| 开放自由对话、改变「发送」仍不可自由下发指令 | 属于 [#118](https://github.com/Pedro-MAFS/ftcs/issues/118)；现网发送行为保持 |
| 搬动智能体栏到主区域左侧，或改三大板块宽窄 | CS1；不在 #117 |
| 脱敏规则、入口是按钮还是菜单 | §7 O1、O2；详设选定前不写成已锁定规则 |
| 超限时另存为，或让用户自选保存路径 | CS6、§7 O3。只自动保存到系统下载目录 |
| 超限时把截断后的长文写入剪贴板 | CS6。剪贴板只放一行「会话过长，全文已保存到：路径」。若产品改口要同时放截断版再改 |
| 超限仍截断写入剪贴板，Toast「已复制（内容过长已截断）」 | 2026-11-01 起作废，见 §7 O3 |
| 合入 `main` / 打 tag / 发版 / 关闭 #117 | CS8 |

## 5. 用户故事拆分

```mermaid

  CS01[US-CS-01 复制当前会话]
  CS02[US-CS-02 附带排查元信息]
  CS01 --> CS02
```

| ID | 标题 | 优先级 | 依赖 | 说明 |
|----|------|--------|------|------|
| **US-CS-01** | 复制当前会话到剪贴板 | Must | 现网 `AgentPanel` 时间线；系统剪贴板；超限时的系统下载目录 | 整段、顺序与界面一致；成功提示；空会话提示；超限改存下载目录 |
| **US-CS-02** | 复制文本附带排查元信息 | Must | US-CS-01 | 版本号与复制时间；其余字段待详设 |

两条都留。会话正文可以先用一段不含元信息块的样例验收顺序和空态。元信息块的字段清单要等详设，不宜和正文绑成一次才算过。两次点击仍是同一个入口：US-CS-02 完成后，未超限时剪贴板里同时有正文和元信息；超限时这两部分在下载的全文里。

### US-CS-01　复制当前会话到剪贴板

**作为** 遇到问题的外贸业务员，**我想** 在智能体栏一键复制当前整段对话，**以便** 不用手选和截图，就能把现场交给开发排查。

| 项 | 内容 |
|----|------|
| 优先级 | Must |
| 依赖 | `AgentPanel` 的 `agentTimeline`；现网条目种类 `user` / `assistant` / `tool` 等；系统剪贴板；超限时的系统下载目录 |
| 状态 | **待详设** |

**验收要点**

- 智能体栏上有「复制当前会话」入口（CS1）。按钮或菜单见 §7 O1，详设写明之前，验收只要求入口在这面栏里、用户找得到。  
- 时间线里已有用户消息、智能体回复、工具调用及结果，且脱敏后全文不超过 200_000 时，点击后剪贴板中的对应内容顺序与界面时间线一致，内容为脱敏后全文，不另存文件（CS2、CS6）。  
- 任务仍在进行时也可以复制；带走的是点击瞬间栏里已有的条目，不要求等任务结束（CS2）。  
- 复制成功后有明确提示（CS4）。未超限时，提示表示全文已进剪贴板。超过 200_000 时，Toast 给出所存文件的完整路径，不再使用「已复制（内容过长已截断）」。  
- 脱敏后全文超过 200_000 时：系统下载目录新增一份 `.txt`，文件名为 `ftcs-session-YYYYMMDD-HHmmss.txt`（保存当时的本地时间）；文件内容是脱敏后全文，不是截断版；不弹出另存为，不让用户选路径。剪贴板只有一行「会话过长，全文已保存到：」加该完整路径，没有截断后的会话长文。Toast 中的路径与这一行相同（CS6、§7 O3）。  
- 时间线没有任何条目时有明确提示，剪贴板里不出现空态占位句冒充的对话，也不因此在下载目录落一份会话文件（CS3）。  
- 复制不上传到服务器（CS6）。  
- 复制前后，时间线的条目、折叠状态和任务继续运行的方式与复制前一致；超限落盘不改界面上的全文（CS7）。  
- 本故事不要求版本号和时间。那是 US-CS-02。

**本故事不做**：自动上报；开放自由对话；搬动智能体栏；超限另存为选路径；超限把截断长文写入剪贴板；关闭 #117。

### US-CS-02　复制文本附带排查元信息

**作为** 收到用户反馈的开发，**我想** 在复制出的文本里直接看到应用版本和复制时间，**以便** 对照是哪一个构建、哪一次现场，而不必再向用户追问。

| 项 | 内容 |
|----|------|
| 优先级 | Must |
| 依赖 | US-CS-01 的同一次复制；运行中的应用版本 |
| 状态 | **待详设** |

**验收要点**

- 同一次成功复制的文本中，有可读的应用版本号和复制时间（CS5）。版本号等于当时应用报告的版本，不写死为文档编写时的 `0.6.0`。  
- 会话 / 任务标识、模型或服务状态、报错信息，以及是否附带栏上已有的元信息卡片，由详设列出清单和一段样例后再验收。未列入清单的字段，不作为本故事的失败条件。  
- 未超限时，元信息与 US-CS-01 的会话正文在同一份剪贴板文本里，一次点击完成。超过 200_000 时，二者在同一份下载目录中的全文里；剪贴板只有 CS6 那一行路径提示，不以该行冒充会话正文。摆放位置由详设在样例里写明。  
- 没有会话条目时，仍按 US-CS-01 提示，不以一份只有元信息、没有说明的文本冒充「已复制会话」（CS3）。详设若选择空会话也写入元信息，须在提示里说清，并单独给验收样例。  
- 本故事不改时间线存储与展示（CS7）。

**本故事不做**：规定脱敏算法（见 §7 O2）；把超限会话截断进剪贴板（见 §7 O3）；上传日志；关闭 #117。

## 6. 验收清单（需求级）

- [ ] 智能体栏可以复制当前会话。不超过 200_000 时，脱敏后全文进入剪贴板，顺序与界面时间线一致，含用户消息、智能体回复、工具调用及结果，且不另存文件。  
- [ ] 复制成功有明确提示。未超限时表示已进剪贴板；超过 200_000 时 Toast 给出所存文件的完整路径，不再使用「已复制（内容过长已截断）」。  
- [ ] 会话为空时有明确提示，空态占位句不会被当成对话正文，也不因此落盘。  
- [ ] 复制文本含应用版本号和复制时间，格式可读。未超限时在剪贴板全文里；超限时在下载的全文里。  
- [ ] 超过 200_000 时，脱敏后全文自动保存为系统下载目录中的 `ftcs-session-YYYYMMDD-HHmmss.txt`；剪贴板只有一行「会话过长，全文已保存到：」加完整路径，不放截断全文；不弹另存为。没有自动上报或上传。  
- [ ] 会话的存储和界面展示与复制前一致。  
- [ ] 变更落在 `dev-0.6.1`；#117 不因本文关闭。
