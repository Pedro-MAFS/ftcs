## 1. 已确认选型

| 项 | 决定 |
|----|------|
| **Q1 单击行** | **保持 I-01**：只改焦点；文件夹仍切换展开。**不**因单击而勾选或清空勾选 |
| **Q2 Ctrl** | Ctrl（Mac：⌘）+ 点行或复选框 = **切换该项**勾选，其它项不动 |
| **Q3 Shift** | 从**锚点**到当前行，对**当前可见**节点（含折叠夹的子孙则不算可见）范围勾选。范围外**可见**项取消勾选；**已折叠看不见的勾选保留** |
| **Q4 锚点** | 最近一次 toggle / Ctrl 的节点。Shift 不改锚点。改名/移动后按路径前缀迁移 |
| **Q5 生成** | 仍只收集 `kind === 'file' \| 'website'`。文件夹勾选留给 I-07 |
| **Q6 顶栏** | 「已选 N 项」；按钮 `title` 可注明还不能用文件夹生成 |

## 2. 目标与非目标

### 2.1 目标

1. 能在不同文件夹下勾选多个文件、书签、文件夹。  
2. Ctrl 点选、Shift 范围选，手感接近资源管理器，但不破坏「单击只定焦点」。  
3. 折叠再展开，勾选还在。  
4. 未点「生成画像」前不创建 `prod_*`。

### 2.2 非目标

| 不做 | 归属 |
|------|------|
| 勾选夹后递归带上内部文件再生成 | US-I-07 |
| 一次拖动/Delete 多个勾选项 | 明确不做（I-03 仍只移动被拖的那一行） |
| 根「资料库」可勾选 | 与 I-01 一致 |

## 3. 界面

顶栏旁注：`已选 N 项`。N = 当前树中仍存在的勾选节点数。

文件夹复选框启用。`title`：「勾选该文件夹（生成画像时暂不递归）」。

点文件夹 **chevron** 仍只展开/折叠，不改勾选。

---

## 4. 行为细则

### 4.1 可见序列

与树渲染相同：已展开目录的子节点按深度优先出现。Shift 只在这条序列上取下标。

### 4.2 `applyLibrarySelect`

纯函数（`library-select.ts`）：输入当前勾选、可见 id 列表、目标、手势、锚点；输出新勾选与新锚点。

| 手势 | 勾选 | 锚点 |
|------|------|------|
| `toggle` / `ctrl` | 切换目标 | 目标 |
| `shift` | 可见项先清掉再勾上区间；不可见勾选保留 | 原锚点（若锚点已不在可见列，则区间退化为仅目标） |

### 4.3 生成

`canGenerate` = 勾选中至少 1 个文件或书签。仅勾文件夹时按钮禁用。
