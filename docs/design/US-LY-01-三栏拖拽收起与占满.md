## 3. O1　最小宽度与分母

> **已确认（2026-11-01）：按详设推荐**

| | |
|--|--|
| **推荐** | 分母是身体区里「展开栏所分的那一段」。图标轨 48，收起栏 44，分隔条 6。展开最小宽度：流水线 **200**，智能体 **300**，主视图 **360**。意图宽度默认仍对应现网 236 与 340 |
| **备选** | 分母用整窗客户区宽度，三栏连同图标轨一起按百分比。最小宽度改成流水线 236、智能体 340、主视图 480 |
| **理由** | 图标轨和收起栏在稿里是固定像素。把它们放进百分比，收起一次比例就会跳。备选在 `minWidth: 960` 时是 48+236+6+480+6+340 = 1116，大于 960。推荐值是 48+200+6+360+6+300 = 920，放得下。智能体 300：标题行要留下技能名省略号、「复制会话」和两枚 28px 图标。流水线 200 放下「产品」、新建和收起。主视图 360 高于现网在 960 上大约 336 的剩余；线索表已有横向滚动 |
| **样例** | 窗口客户区宽 1180，两栏展开。首次打开，流水线 236、智能体 340，其余给主视图。拖到流水线不再变窄时是 200，松手后仍是展开，五步还在。窗口改成 960：三栏都不低于 200 / 360 / 300。拉回 1180 且用户没在 960 上拖过：又是 236 和 340。收起流水线：该栏 44，已保存比例不变；再展开，宽回到收起前按同一比例算出的像素 |

### 3.1 公式

```ts
interface LayoutRatios {
  pipeline: number
  main: number
  agent: number
}

interface LayoutSnapshot {
  ratios: LayoutRatios
  pipelineCollapsed: boolean
  agentCollapsed: boolean
}

interface MainViewLayout {
  ratios: LayoutRatios
  pipelineCollapsed: boolean
  agentCollapsed: boolean
  fill: 'none' | 'main' | 'agent'
  beforeFill: LayoutSnapshot | null
}
```

三份比例都大于 0，和为 1。它们是用户意图，不是夹取后的像素。首次没有记录时：流水线 `0.2107`、主视图 `0.4857`、智能体 `0.3036`。默认窗宽 1180 时 `D = 1180 - 48 - 12 = 1120`，像素约为 236、544、340。余数像素加到主视图。收起位默认 false，`fill` 默认 `'none'`，`beforeFill` 默认 null。

```text
身体区宽度 = workspace__body 的 clientWidth
固定占用 = 图标轨（可见时 48，否则 0）+ 收起栏（每栏 44）+ 分隔条（未占满时 12，占满时 0）
D = 身体区宽度 - 固定占用
```

D 只分给当前展开的栏，按它们的比例重新归一化。收起不改写比例。占满不用 D：该栏等于身体区宽度，其余为 0，比例不写成 `1, 0, 0`。

夹取只影响当次像素，窗口 `resize` 不写回比例。先按比例分，再把低于最小宽度的展开栏抬到最小宽度；缺口先扣主视图，主视图已到 360 再扣另一栏。960 宽上默认比例会先算出流水线约 190、智能体约 273，再夹成 200 和 300，主视图 400。用户没拖过的话，拉宽后仍是 236 / 340 那组比例。

只有分隔条两侧都展开且 `fill === 'none'` 才可拖。贴着收起栏的条照画，不改宽度。拖的是像素；松手把展开像素换算回和为 1 的比例。拖到最小即停，松手仍是展开。

写盘时机：`pointerup`、收起、展开、进入占满、退出占满。拖拽过程中不写。通道形状见 US-LY-04。

### 3.2 状态转移

| 当前 | 动作 | 结果 |
|------|------|------|
| `fill === 'none'` | 拖到最小以上 | 更新比例。收起位不变 |
| `fill === 'none'` | 拖到最小 | 停在最小像素。收起位不变 |
| `fill === 'none'` | 点击流水线或智能体收起 / 展开 | 只翻转对应收起位。比例不变 |
| `fill === 'none'` | 点击主视图占满或智能体占满 | `beforeFill` 记下当前比例和两个收起位，再设 `fill` |
| 已是同一种占满 | 再点占满 | 无操作 |
| 已占满 | 「退出占满」 | 比例和收起位回到 `beforeFill`，`fill = 'none'`，`beforeFill = null` |
| 已占满 | 拖拽 | 没有分隔条 |
| 任意 | 「恢复默认」 | 界面上没有这个控件 |

## 4. O10　头像字

> **已确认（2026-11-01）：按详设推荐**

用产品显示名（侧栏那条 `name`，公司名优先）。

| | |
|--|--|
| **推荐** | `trim` 后按字素取第一个。拉丁字母显示为大写。汉字、假名、数字原样。开头是标点或符号则跳过，直到字母、数字或汉字；跳完仍空则用「产」。当前产品：32px 圆，描边 `#3B82F6` 1px，底 `#1F2B3D`，字 `#3B82F6`。其他产品：无描边，底 `#262626`，字 `#E4E4E4`。点击仍是 `selectProduct`。悬停标题用完整产品名 |
| **备选** | 只取 UTF-16 第一码元；空名不画圆；拉丁名也取小写原样 |
| **理由** | 03 屏已经锁定「华」「北」和当前产品蓝圈。字素可以避开把 emoji 切成半个。空名仍要占一格。数字保留，是为了 `3M` |
| **样例** | `华茂精密` 当前 → 「华」，蓝色描边。`北辰机电` 非当前 → 「北」，无描边。`Acme Valves` → `A`。`  acme` → `A`。`3M` → `3`。`—华茂` → 「华」。空字符串或 `***` → 「产」。收起栏里看不到产品副标题，也看不到五步 |

收起后新建按钮不在窄栏上。新建仍在展开态的产品标题行。
