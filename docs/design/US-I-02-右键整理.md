## 1. 已确认选型

| 项 | 决定 |
|----|------|
| **Q1 菜单实现** | **渲染进程自定义菜单**（Teleport 到 `body`），不用 Electron `Menu`。便于禁用占位项、与现有暗色 UI 一致，且不被树的 `overflow: auto` 裁切 |
| **Q2 右键与焦点** | 右键先把焦点落到该目标（文件夹 / 文件父夹 / 根），**不**切换展开。随后菜单动作复用 I-01 的 `focusDir` |
| **Q3 占位项** | 菜单里**显示但禁用**：「保存网站」「导入文件夹」「重命名」，`title` 说明后续故事。不得把这些能力做进顶栏 |
| **Q4 根行** | 「资料库」当作根文件夹菜单（新建 / 粘贴到此 / 上传到此），**不可删除、不可重命名** |
| **Q5 空白处** | 树容器空白（含空态）右键 = 根 `''`，文案用「新建文件夹 / 粘贴 / 上传文件」（无「到此」） |
| **Q6 键盘** | **保留** Ctrl+V 贴到焦点目录；**本故事增加** Delete 删除当前焦点文件/夹（根不删）。F2 归 I-03 |
| **Q7 网站区** | 面板上部 URL +「保存网站」保留到 I-05；不是顶栏整理按钮 |

## 2. 目标与非目标

### 2.1 目标

1. 顶栏主区只剩「生成画像」，旁注已选网站/文件数。  
2. 空白、根、文件夹、文件各有对应右键菜单；删除需确认。  
3. 新建 / 粘贴 / 上传的落点与 I-01 相同语义：文件夹 = 该夹，文件 = 父夹，未选/空白/根 = `''`。  
4. 空库能靠右键添加资料。

### 2.2 非目标

| 不做 | 归属 |
|------|------|
| F2 / 右键重命名真正改名 | US-I-03（本故事菜单占位） |
| 拖到另一夹移动 | US-I-03 |
| 拖入或右键导入整棵文件夹 | US-I-04（本故事菜单占位；拖入仍只导入文件） |
| 右键「保存网站」写入当前夹 | US-I-05（本故事菜单占位；顶栏上方 chips 仍可用） |
| 网站书签节点自己的菜单 | US-I-05 |

## 3. 界面

### 3.1 顶栏

```text
产品录入                              已选网站 N / 文件 M    [生成画像]
```

不再出现「新建目录」「粘贴文件」「上传文件」。资料区标题「资料库」下不再重复计数（计数只在顶栏旁注）。

### 3.2 菜单内容

| 目标 | 可用 | 禁用占位 | 无 |
|------|------|----------|----|
| 空白 / 空态 | 新建文件夹、粘贴、上传文件 | 导入文件夹 | 删除、重命名、保存网站 |
| 根「资料库」 | 新建文件夹、粘贴到此、上传到此 | 保存网站、导入文件夹 | 删除、重命名 |
| 文件夹 | 新建子文件夹、粘贴到此、上传到此、删除 | 保存网站、导入文件夹、重命名 | — |
| 文件 | 删除 | 重命名 | 新建 / 粘贴 / 上传 |

删除项用危险色，与上方项用分隔线隔开。占位项 `title`：

- 保存网站：「后续版本：写入当前文件夹」
- 导入文件夹：「后续版本：从资源管理器导入整棵目录」
- 重命名：「后续版本」

### 3.3 空态

> 当前还没有资料。在空白处右键可新建文件夹、粘贴或上传文件。

### 3.4 新建目录输入条

仍用现网 `mkdir-row`（插在树顶），不再从顶栏打开。右键「新建…」后显示；回车创建、Esc 取消。创建到**当前焦点目录**（刚被右键设好）。

## 4. 行为细则

### 4.1 打开 / 关闭

- `contextmenu` `preventDefault`，避免系统菜单。  
- 菜单位于指针处；超出视口则向内收。  
- 左键点菜单外、Esc、滚动树容器、busy 开始时关闭。  
- 在另一节点再右键：关掉旧菜单，按新目标打开。  
- `busy` / 生成中不打开菜单。

### 4.2 落点（与 I-01 Q3 对齐）

右键时立刻：

| 目标 | `focusDir` | `activePath` | 展开 |
|------|------------|--------------|------|
| 空白 / 根 | `''` | `''` | 不改 |
| 文件夹 | 该夹 `relativePath` | 同左 | **不** toggle |
| 文件 | `parentDir(rel)` | 文件 `rel` | 不改 |

之后「新建 / 粘贴 / 上传」继续调用现有 IPC（`createLibraryFolder` / `pasteClipboardFiles` / `uploadLibraryFiles`），参数仍是 `focusDir`。

### 4.3 删除

与 I-01 相同：`window.confirm` 后 `deleteLibraryEntry`；删焦点夹则焦点回父夹。根不可删。

Delete 键：焦点为文件或文件夹时走同一套确认；焦点在输入框内或根上则忽略。

### 4.4 不改 IPC

不新增主进程接口。网站 chips、勾选生成、拖入文件 skip 文件夹，均保持 I-01。
