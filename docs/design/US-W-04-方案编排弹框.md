## 1. 待详设要点

### 1.1 入口（挂在方案下拉）

| 操作 | 条件 |
|------|------|
| **＋ 新建方案…** | 始终可用 |
| **编辑当前方案…** | 当前为用户方案；builtin → disabled 或只读 |
| **删除当前方案…** | 当前为用户方案；确认框 |

### 1.2 弹框 `WorkflowPlanEditorDialog.vue`

- **名称**：单行输入，max 40 字。  
- **步骤列表**：每行 = 节点目录下拉 + 删除；底部「添加步骤」。  
- **排序**：上移 / 下移按钮（v1）；不做 drag-drop。  
- **保存** → `saveWorkflowPlan`；**取消** 丢弃。

### 1.3 校验

- 至少 1 步；名称 trim 非空；用户方案名称不重复。  
- 步骤只允许 §4 节点 ID。
