# US-FD-04 / US-FD-05：画像与中文对照聊天启动

来源：Issue #141。承接 docs/40 §11；本扩项替代 US-FD-03 中画像/中文对照不支持的范围说明，不修改其六步骤验收。

## 题头契约

stage 由最近加载的步骤技能决定，`阶段` 若出现须与之相符。普通问题不进入启动链路。

| 技能 | stage | 必填题头 | 可选题头 |
| --- | --- | --- | --- |
| extract-product-profile | profile | 产品（单选 `新建`）、资料（多选真实资料库文件相对路径） | 阶段 |
| translate-outreach-email | translate | 产品（真实 ID）、线索（真实 ID） | 收件槽（默认 company）、阶段 |

全部 custom=false；除资料外均单选。拒绝重复题头、跨步骤题头、空必填与未知阶段。资料不是任意 URL 输入：仅引用已录入 `data/library/files` 的文件/网站书签；公司名称用于寻找候选，用户选择来源后确定新产品身份。既有产品的重建也新建快照，不静默覆盖旧 ID。资料准备不属于本期。

## 执行接线

1. `question.asked` 复用 US-AQ 卡片；提交成功且 fresh 才解析，取消和超时沿用拒绝逻辑。
2. `launchChatTask` 校验资料真实路径（含符号链接边界）或产品 ID。画像按网站书签分流后调用 extract-profile 预检，仅网站需要内置浏览器；翻译使用 draft-email 预检。
3. 画像调用与按钮相同的 bootstrapProductFromLibrary：分配 ID、复制 inputs、抽 Office/PDF 侧车、写 _sources.json；全无可用资料则报错。再次检查取消，再调用 runExtractProfile。
4. 翻译先只读校验 ID/收件槽为安全单路径段、真实文件不越出工作区、product_id 归属一致且外文主题/正文非空；缺少归属也拒绝。通过后调用 runTranslateOutreachEmail，继续复用 getEmailDraftSlot 与正式翻译链路。个人槽不回退公司槽。
5. 两条 run 增加可选 fromChat，采用现有延迟切会话协议：创建成功才中止旧回复、切任务时间线并进入 running。预检/创建失败追加失败说明，保留原对话。按钮调用不传该选项。
6. 完成、错误与状态事件沿用现有 run，权限仍由原 permission gate 控制。工作区同步版本随技能更新，不新增 MCP 或权限白名单。

## 边界与取舍

- 仅原始 URL、裸 productId、或聊天里提到外文内容不足以绕过桌面参数准备；技能缺必填即提问并停止。任务提示词已携带准备好的 inputs/外文稿则直接执行。
- bootstrap 已开始后用户取消，停止后续 run；已经复制的本地快照保留，避免异步清理误删。卡片取消发生在 bootstrap 前，不产生快照。
- 资料库中文文件名可用；拒绝绝对路径、父级路径、目录和越界链接。
- 不增加第二张授权卡，不修改六步骤业务，不扩展补联系人或单封重写。

## 独立验收

自动化覆盖题头解析、混合资料分流及越界拒绝、公司/个人收件槽、正式 run 会话切换、取消和创建失败保留对话。人工联调需在桌面重启同步后验证：真实模型产生提问卡、选定资料后画像状态与页面刷新、翻译目标槽中文显示、取消不启动；原有六步骤按原清单独立回归。
