> **用户故事**：[../32-需求-界面文案精简.md](../32-需求-界面文案精简.md) · US-COPY-05 · Related #66  
> **状态**：待开发（本文只定界面文案；不改功能）  
> **范围**：更新横幅、设置页里同一条更新结果、Toast，以及会直接显示给用户的失败句（含启动前检查的用户可见摘要）  
> **依赖**：US-COPY-04 的术语；`docs/32` §6.8、COPY9；诊断信息区定义见 [US-COPY-02](US-COPY-02-设置集成工作区与隐私文案.md) §2

两类句子分开：

| 类型 | 用户看见 | 例子 |
|------|----------|------|
| 内部失败 | 操作失败，请重试 | 接口不可用、读站点失败、异常原文、HTTP 状态码 |
| 配置引导 | 保留「请到设置…」这种下一步，但去掉禁用词 | 缺 Key 仍用 US-COPY-01 的两句，不改成笼统的「操作失败」 |

## 1. 位置 → 最终文案

### 1.1 更新横幅与设置页更新结果

`useUpdateCheck` / `update-banner-model` 的失败行，横幅和设置 · 关于里是同一句。

| 区域 / 位置 | 旧文案要点 | 最终文案（定稿） | 备注 |
|-------------|------------|------------------|------|
| 检查失败 | 检查更新失败：{原始错误}，例如「检查更新失败：HTTP 500」 | 检查更新失败，请重试或前往官网下载 | 原始错误只进诊断信息。不拼接 `message` |
| 下载失败等其它更新错误 | 若现网把异常原文放进横幅 | 更新失败，请重试或前往官网下载 | 同样不展示原始错误串 |

检查中、有新版本、前往下载等现有可用文案保持不动。

### 1.2 内部失败兜底

下面这些现网句子会进 Toast 或页面提示。全部改为「操作失败，请重试」。原始字符串复制进诊断信息。

| 区域 / 位置 | 旧文案要点 | 最终文案（定稿） | 备注 |
|-------------|------------|------------------|------|
| 社媒站点读取 | 无法读取 R2 站点 | 操作失败，请重试 | `SettingsView` 读取站点失败 |
| 删除草稿 | 删除接口不可用 | 操作失败，请重试 | `useWorkspace` |
| 新建草稿 | 新建草稿接口不可用 | 操作失败，请重试 | `useWorkspace` |
| 扩展关键词 | 扩展关键词接口不可用 | 操作失败，请重试 | `useWorkflowExecute` |
| 评分去重 | 评分去重接口不可用 | 操作失败，请重试 | 同上 |
| 批量起草 | 批量起草接口不可用 | 操作失败，请重试 | 同上 |
| 批量补全 | 批量补全接口不可用 | 操作失败，请重试 | 同上 |
| 运行时未就绪却被 Toast 原样抛出 | OpenCode 未运行 / 未初始化 / 未就绪，请先在设置页确认运行时状态 | 服务未就绪，请稍后或重启应用 | 与 US-COPY-02 的空态同一句。不要用「操作失败」盖住这句可行动提示 |

规则：此后新增的用户可见失败，如果 `message` 来自异常、HTTP 或内部英文/路径，界面用「操作失败，请重试」，不把 `message` 拼进 Toast、横幅或页面红字。

### 1.3 启动前检查（用户可见摘要）

`runAgentPreflight` 的失败摘要会展示给用户。检查项 id 和调用顺序不改。主摘要不得出现 OpenCode、MCP、技能名、R3。

| 区域 / 位置 | 旧文案要点 | 最终文案（定稿） | 备注 |
|-------------|------------|------------------|------|
| 运行时项标题 | OpenCode 运行时 | 智能体服务 | |
| 运行时未就绪 | 未就绪。请到设置页确认本机已安装 OpenCode，或点击「重启 OpenCode」 | 服务未就绪，请稍后或重启应用 | 启动中仍可用「正在启动，请稍候再试」 |
| 运行时就绪详情 | healthy | 已就绪 | 不把英文状态给用户 |
| 其它任务 | 无其它 Agent 任务 | 没有其它任务在运行 | |
| 搜索已开通详情 | 官方通道 · 搜索复用网关凭证 | 官方通道已包含搜索 | |
| 地图发现项 | Google Places（R3） | 地图发现 | |
| MCP 项标题 | MCP lead-store / MCP search-api / MCP chrome-devtools / MCP places-api / MCP hunter-api | 线索服务 / 搜索服务 / 浏览器 / 地图服务 / 联系人服务 | |
| MCP 未发现或未连接 | 未在 OpenCode 中发现 MCP「…」；请在设置中查看 MCP 状态；以及连接错误原文 | 服务未就绪，请稍后或重启应用 | 服务名和 `item.error` 放进诊断信息 |
| 总失败抬头 | 环境未就绪，请先完成配置后再启动 AI 任务 | 还有步骤没准备好。请按下面的说明处理后再试。 | 下面每条用上表的用户句，不用内部 label |

缺 Key、欠费、吊销仍用 US-COPY-01 已定的句子，不用本节的「操作失败，请重试」替换。

## 2. 禁用词验收（本故事界面）

横幅、Toast、页面红字、启动前检查的用户可见摘要不得出现（诊断信息区除外）：

- [ ] R1、R2、R3
- [ ] OpenCode、MCP、Token 网关
- [ ] `.env`、`opencode.json`、`data/`、`discover-*`、`keywords_save`、`hunter_*`、US-xx
- [ ] Clash、TUN、VPN、翻墙、`127.0.0.1:7890`
- [ ] 「接口不可用」「无法读取 R2 站点」以及 HTTP 状态码、异常原文

诊断信息里可以保留上述技术细节，并提供复制。

## 3. 验收清单

- [ ] 更新检查失败的横幅和设置页都是「检查更新失败，请重试或前往官网下载」，没有原始错误。
- [ ] §1.2 列出的内部失败都显示「操作失败，请重试」；运行时未就绪显示「服务未就绪，请稍后或重启应用」。
- [ ] 启动前检查摘要无 OpenCode、MCP、R3；可行动的配置句仍然在。
- [ ] 原始错误只出现在可复制的诊断信息中。
- [ ] 更新检查、下载、失败上报、预检判定条件与改前一致。
- [ ] 单条用户提示一般不超过 3 行。
