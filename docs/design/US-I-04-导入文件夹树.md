## 1. 已确认选型

| 项 | 决定 |
|----|------|
| **Q1 入口** | **拖入**（落点 = I-02 已做的目标夹）+ **右键「导入文件夹」**（对话框 `openDirectory` + 可多选）。不进顶栏 |
| **Q2 根名** | 导入后在落点下出现**与源夹同名**的一层（经现网 `sanitizeBaseName`），不是把源夹内容摊到落点根上 |
| **Q3 重名** | 落点下已有**同名目录则合并**（缺的子夹补上，文件冲突走现网 `uniquePath` 加 `-2`）；已有同名**文件**则目录改用 `name-2` |
| **Q4 上限** | 单次导入最多 **5000** 节点、源树深度 **16**（与浏览上限同值）。超限停止并提示，已写入的保留 |
| **Q5 符号链接** | **跳过**，不跟随，避免逃出源树或环 |
| **Q6 资料库自引用** | 源路径在 `files/` 内，或源夹**包含**当前 `files/`，整项跳过并说明原因 |

## 2. 目标与非目标

### 2.1 目标

1. 拖一个已整理好的公司/产品夹到树上，树里能看到对应子夹与文件（含空夹）。  
2. 右键能选夹导入到焦点目录。  
3. 非法路径、无权限、自引用给出可读跳过原因，不崩。

### 2.2 非目标

| 不做 | 归属 |
|------|------|
| 改名保留空格 | US-I-03（本期目录名仍走 `sanitizeBaseName`） |
| 树内拖到另一夹 = 移动 | US-I-03 |
| 导入后自动生成画像 | 明确不做 |

## 3. 行为细则

### 3.1 落点

与 I-02 拖入文件相同：文件夹行 = 该夹；文件行 = 父夹；根 / 空白 = `''`。

源 `D:\工作\绿森塑木` 落到 `客户A/` → `files/客户A/绿森塑木/…`。

### 3.2 折叠重复路径

资源管理器拖夹时，FileList 可能同时带上夹路径和内部文件。主进程对路径做：

1. `path.resolve` 去重  
2. 若某路径位于另一**已选目录**内部，丢掉该路径（由父夹整棵导入）

只选中若干文件、没有任何目录路径时：仍按文件导入到落点（不猜测公共父夹，以免和「多选文件上传」混淆）。

### 3.3 跳过文案（写入 `skipped`）

| 情况 | 文案 |
|------|------|
| 不存在 | `（找不到源文件）` |
| 无权限 / 读失败 | `（无权限或无法读取）` |
| 符号链接 | `（跳过符号链接）` |
| 名称含 `..` 或非法后为空 | `（非法名称）` |
| 源在资料库内 / 源包含资料库 | `（不能从资料库内部导入）` / `（所选文件夹包含当前资料库）` |
| 超上限 | 追加一条总提示，不针对每个剩余节点 |

### 3.4 成功消息

- 有文件：`已导入 N 个文件`  
- 有新建目录：`已创建 M 个文件夹`  
- 仅空夹也算成功（`ok === true`）

## 5. 验收用例

| # | Given | When | Then |
|---|--------|------|------|
| A1 | 源夹 `绿森/地板/a.md` + 空夹 `绿森/墙板` | 拖到根 | 树有 `绿森/地板/a.md` 与空的 `绿森/墙板` |
