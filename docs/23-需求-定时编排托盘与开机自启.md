# 23 - 需求：定时编排 · 托盘常驻与开机自启

> **文档类型**：本期需求 + 用户故事（**US-T** Tray/Login + **US-W-06** 定时）  
> **状态**：**v0.5.6 已交付（2026-09-30）** — 托盘常驻、开机自启、定时 CRUD 与调度触发  
> **基线**：桌面端 **v0.5.5+**（任务编排 `executePlan`、US-N 系统通知已落地）  
> **对齐**：官网支持计划 `scheduled-tasks`（定时运行编排任务）  
> **承接**：[18-需求-任务编排一键跑通.md](18-需求-任务编排一键跑通.md) US-W-06；完成通知见 [22-需求-任务完成Windows通知.md](22-需求-任务完成Windows通知.md)

## 1. 一句话目标

应用可 **关闭进托盘常驻**、可选 **开机自启**，并对已保存的编排方案按 **每日/每周本地时刻** 自动执行；跑完后用现有 Windows 系统通知提醒用户。

---

## 2. 已拍板规则

| # | 规则 |
|---|------|
| **T1** | 点窗口 **×**：默认 **退出应用**；可在设置开启「关闭进托盘」。开启后隐藏到托盘，仅托盘「退出」真正退出。 |
| **T2** | 托盘菜单至少：**显示主窗口**、**退出**。 |
| **T3** | 设置左侧 **「启动与托盘」**：开机自启（默认关）+ 关闭进托盘（默认关）；配置定时时引导并 **一键同时开启**（说明：关机后需自启拉起，关窗后需托盘常驻）。 |
| **S1** | 每条定时绑定 **产品 + 方案**；`daily` 或 `weekly`（选星期）+ 本地 `HH:mm`；可开关。 |
| **S2** | 工作区最多 **5** 条定时任务。 |
| **S3** | 到点触发走现网 `executePlan`；完成/失败通知走 US-N（含编排整段一次）。 |
| **S4** | 若已有方案在跑 → **跳过**本轮，不打断；可弹「定时任务已跳过：有任务进行中」（受任务完成通知开关约束）。 |
| **S5** | 启动补跑：若上一应跑时刻晚于 `lastRunAt` 且距今 ≤ **24h** → 补跑一次；更早漏跑不追。 |
| **S6** | 调度在主进程每分钟对齐；经 IPC 通知渲染进程执行（窗口隐藏但未销毁）。 |

---

## 3. 范围与非范围

### 做

- 系统托盘、关闭进托盘、开机自启。  
- 定时任务 CRUD 与调度触发。  
- 与 US-N 通知复用。

### 不做

| 项 | 说明 |
|----|------|
| Windows 任务计划程序独立进程 | 应用未运行时不唤醒 |
| 复杂 cron / 每 N 小时 | 仅每日/每周 |
| 点击通知跳业务页 | 沿用 N4 |
| macOS / Linux 验收 | 产品以 Windows 为准 |

## 4. 数据

### 4.1 本机 prefs

| 字段 | 默认 | 说明 |
|------|------|------|
| `openAtLogin` | `false` | 开机自启 |

### 4.2 工作区 `data/prefs/workflow-schedules.json`

```json
{
  "version": 1,
  "schedules": [
    {
      "id": "sch_xxx",
      "productId": "prod_xxx",
      "planId": "builtin-standard",
      "enabled": true,
      "recurrence": "daily",
      "weekday": null,
      "timeLocal": "09:00",
      "lastRunAt": null,
      "createdAt": "...",
      "updatedAt": "..."
    }
  ]
}
```

`weekly` 时 `weekday` 为 0–6（周日=0，与 `Date.getDay()` 一致）。

## 5. 用户故事

| ID | 标题 | 优先级 | 依赖 |
|----|------|--------|------|
| **US-T-01** | 托盘与关闭进托盘 | Must | — |
| **US-T-02** | 开机自启 | Must | T-01 |
| **US-W-06a** | 定时任务模型与 UI | Must | T-01 |
| **US-W-06b** | 调度触发与执行 | Must | T-01、W-06a、US-N |

实现顺序：**T-01 → T-02 → W-06a → W-06b**。

### US-T-01　托盘与关闭进托盘

- × → hide，进程与 OpenCode 仍在。  
- 托盘「显示主窗口」→ show + focus；「退出」→ 走现网 `before-quit` 清理。

### US-T-02　开机自启

- 设置开关保存后同步 `app.setLoginItemSettings`。  
- 自启参数含 `openAsHidden`；启动时若判定为登录自启则不强制弹主窗。

### US-W-06a　定时任务模型与 UI

- 线索页或独立区块：列表 / 新建 / 编辑 / 删除 / 开关。  
- 校验：产品存在、方案存在、最多 5 条、`timeLocal` 合法。

### US-W-06b　调度触发与执行

- 主进程 tick；到点发 `schedule:run`；渲染切产品后 `executePlan`。  
- 更新 `lastRunAt`；跳过与 24h 补跑按 S4/S5。
