# 16 - 官方搜索通道用户故事（Desktop）

> **文档类型**：消费方用户故事（外贸获客桌面端 · 搜索）  
> **状态**：桌面对接已落地（2026-08-08）  
> **实施**：依赖网关 Phase G5 契约；对接规格见 [15-官方搜索通道对接.md](./15-官方搜索通道对接.md)  
> **网关故事**：[`token-gateway/docs/02-用户故事.md`](../token-gateway/docs/02-用户故事.md) §3.7  
> **对照**：模型通道故事 [12-官方模型通道用户故事.md](./12-官方模型通道用户故事.md)

---

## 1. 背景

今日搜索由本机 MCP 直连 Tavily，用户必须自备 Key。G5 起：选择**官方模型通道**的用户，搜索应复用官方 `sk-` 走网关按次计费；**自定义模型通道**仍自备 Tavily Key。

---

## 2. 故事列表

### US-FTCS-S01　官方通道下搜索免配 Tavily Key

**作为** 已开通官方模型通道的用户，**我想** 不再填写 Tavily API Key 也能搜索，**以便** 降低探索主路径摩擦。

| 字段 | 内容 |
|------|------|
| 优先级 | Must |
| 依赖 | 网关 US-G5-01～03；桌面已具备官方 sk |
| 验收要点 | 官方通道下搜索 Key 置灰；`search_web` 成功；未配置 Tavily Key 仍可通过预检 |

### US-FTCS-S02　自定义通道仍自备 Tavily

**作为** 使用自定义模型的用户，**我想** 继续使用自己的 Tavily Key，**以便** 不强制绑定官方余额。

| 字段 | 内容 |
|------|------|
| 优先级 | Must |
| 依赖 | 现网 search-api |
| 验收要点 | 自定义通道下 Key 可编辑；直连 Tavily；不扣官方余额 |

### US-FTCS-S03　通道切换时搜索凭证联动

**作为** 用户，**我想** 在官方/自定义之间切换时搜索凭证状态自动正确，**以便** 避免误用 Key 或误以为已计费。

| 字段 | 内容 |
|------|------|
| 优先级 | Must |
| 依赖 | US-FTCS-S01，US-FTCS-S02 |
| 验收要点 | 切官方 → 置灰并走网关；切自定义 → 恢复输入框；文案不互相矛盾 |

### US-FTCS-S04　官方搜索失败可理解提示

**作为** 官方通道用户，**我想** 在余额不足或 sk 失效时看到明确提示，**以便** 去充值或重新开通通道。

| 字段 | 内容 |
|------|------|
| 优先级 | Should |
| 依赖 | 网关 401/402 映射 |
| 验收要点 | 402 → 引导余额/充值；401 → 引导检查官方通道凭证 |

## 3. 明确不做

| 项 | 说明 |
|----|------|

| 桌面自建搜索计费账本 | 用网关余额 |
| 修改探索业务步骤语义 | 仅换传输与凭证 |
