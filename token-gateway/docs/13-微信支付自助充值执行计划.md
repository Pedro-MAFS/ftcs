# Token 网关 · 微信支付自助充值执行计划（Phase G3）

> **目标**：个体工商户主体接入微信支付，用户自助付款后余额入账 `token_users.balance_li`（厘），并写 `token_ledger_entries(type=topup)`。  
> **原则**：经营场景如实申报；支付成功才入账；入账与流水同事务；回调幂等。  
> **现状锚点**：G0 已有人工 topup 约定（US-G0-15）；自助支付属 Phase G3。  
> **约束**：个体户执照、无对公户（法人个人卡结算）、网站已备案但备案主体为个人。  
> **用户故事**：[`02-用户故事.md`](./02-用户故事.md) Phase G3。

按阶段顺序做；**未完成上一阶段「出门条件」不要跳到编码联调。**

---

## 已拍板产品决策（2026-08-03）

| 项 | 决定 |
|----|------|
| 产品口径 | **官方通道预付费充值**（付人民币 → 账户余额厘 → 官方通道按量扣费） |
| 套餐 | **暂不支持**；用户自填金额 |
| 单笔金额 | **最低 1 元，最高 100 元**（1000～100000 厘） |
| 退款 | **仅人工**；对外承诺 **3 个工作日内**处理（系统不做自动退款 API） |
| 支付方式（技术默认） | Native 扫码（AppID 可开发联调前再绑定） |
| 充值 UI | **Token 网关托管充值页**；客户端只做跳转入口 |
