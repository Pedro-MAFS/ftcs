# Token 网关 · Tavily 搜索中转计费执行计划（Phase G5）

> **目标**：网关封装上游 Tavily Search；用户凭官方通道 `sk-` 调用搜索；**按次**扣官方余额；计量伪 model = `tavily.search`。  
> **原则**：复用 G0 鉴权 / 余额预检 / request_logs / price_rules / 异步结算；**不落检索 query 全文**（仅摘要）；上游 Key 仅服务端。  
> **现状锚点**：Chat 代理与计费已落地；桌面仍 BYOK 直连 Tavily（见宿主文档）。  
> **用户故事**：[02-用户故事.md](./02-用户故事.md) §3.7 Phase G5。  
> **总览设计**：[design/US-G5-00-搜索中转计费总览设计.md](./design/US-G5-00-搜索中转计费总览设计.md)  
> **桌面需求（分册）**：宿主仓库 [`docs/15-官方搜索通道对接.md`](../../docs/15-官方搜索通道对接.md)（**不在本执行计划展开实现**）

按阶段顺序做；**未完成上一阶段「出门条件」不要跳到编码联调。**  
**先网关、后桌面**：本计划阶段 C 出门后，再启动宿主 G5 桌面故事。

## 已拍板产品决策（2026-08-07）

| 项 | 决定 |
|----|------|
| 阶段 | **Phase G5**（G4 面板之后；可与桌面分册并行文档，实现串行） |
| 鉴权 | 与 Chat 相同：`Authorization: Bearer sk-…`（G0-08） |
| 计价 | **按次**（代理路径**成功或失败**均计 1 次）；价目挂伪 model `tavily.search`；编码 **方案 A**（li/次×1e6 写入 input 列） |
| 落账 | 复用 `token_request_logs` / `token_price_rules` / 异步结算；`model=tavily.search` |
| 费率维护 | 与 Chat 同轨：`token_price_rules` **只 INSERT** 新 `effective_from`；运维 SQL；**无**管理端调价 UI |
| 面板展示 | **要做**：扩展「价格」Tab / `…/prices`，展示 `tavily.search` **元/次**（US-G5-04）；消费列表自然出现即可 |
| 隐私 | **只落摘要**（如结果条数、depth、latency、error_summary）；**不**落 query / 结果正文 |
| 上游 | 网关持有 `TAVILY_API_KEY`；不向客户端回传 |
| 桌面 UX（宿主文档） | 官方模型通道 → 搜索 Key **置灰**，自动用与模型相同的官方 `sk-`；自定义模型 → 用户自备 Tavily Key |
| 双模搜索 | 官方通道走网关计费；自定义通道仍可直连 Tavily（BYOK），不经网关 |

## 与 Chat 计费对齐（实现约束）

| 项 | 约定 |
|----|------|
| 请求内 | **不算价、不扣费**（OQ-07） |
| 计量 | 代理路径成功/失败均写按次 usage → `billing_status=pending`；参数校验/鉴权预检失败不写（见 US-G5-03） |
| 按次映射 | **已冻结方案 A**（见 [US-G5-03](./design/US-G5-03-搜索按次计量与结算设计.md)）：`prompt_tokens=1` + `input_price_li_per_mTok = li_per_call × 1e6`；**不做** `li_per_call` 扩列 |
| 预检 | 至少能覆盖 1 次搜索单价（`min-balance` 或按价目估算） |
