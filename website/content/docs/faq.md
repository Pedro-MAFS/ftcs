# 常见问题

<h2 id="what-is-ftcs">FTCS / 外贸获客智能体是什么？</h2>

FTCS 是 AI-Utills 旗下的 Windows 桌面外贸获客智能体（Agent）。在本机把产品资料变成画像、公开网页线索和可改稿开发信。产品站：[ftcs.ai-utills.com](https://ftcs.ai-utills.com/)。品牌站：[ai-utills.com](https://ai-utills.com/)。

<h2 id="vs-customs-linkedin">外贸获客系统和海关数据、领英开发有什么不同？</h2>

海关数据给你进口记录，领英销售工具帮你找联系人。FTCS 从你的产品画像出发，在公开网页广撒网，也可按领英、脸书等公开主页的搜索摘要发现公司并核对官网，再写出可改稿的开发信。不登录社媒、不代替领英开发——获客闭环留在本机。

<h2 id="data-and-send">数据会上传到官网吗？现在能直接发开发信吗？</h2>

业务数据与密钥只在你电脑上，官网只做展示与下载。开发信先生成可改稿草稿，你确认后再用，发出节奏由你掌握，避免误触达客户。

## 使用排障

## 标题栏一直显示未就绪 / 启动失败

- 确认 `node -v` 为 **v22 及以上**，且 OpenCode 可用（应用内一键安装或 `opencode --version`）  
- 检查是否被安全软件拦截本机端口（默认 OpenCode 端口可参考桌面端文档）  
- 在设置中查看 OpenCode 日志  

## 画像 / 探索时报浏览器或 chrome-devtools 相关错误

- 确认已安装 **Google Chrome** 且能手动打开  
- Electron 自带界面浏览器不能代替本机 Chrome  
- 重启应用后再试；必要时更新 Chrome 到较新版本  
- 若页面出现人机验证或登录墙，智能体会停下，请不要尝试绕过；可换下一条线索或改用社媒发现（不打开社媒真页）  

## 广撒网和社媒发现有什么不同？

探索页（以及线索页）可以二选一开始：

- **广撒网**（R1）：按关键词检索公开网页，并打开候选公司官网后写入线索。  
- **社媒发现**（R2）：只检索你在设置里启用的站点（默认 LinkedIn 公司页、Facebook 公共主页）的公开搜索摘要，抽出公司并核对官网后再写入。**不会登录、也不会打开领英 / 脸书真页。**  

改站点开关后需要重新扩展关键词。两种探索不共用同一次任务，可分开跑。

## 探索没有线索

- **官方通道**：确认已开通官方通道且运行时正常（R1/R2 搜索无需单独 Key）  
- **自定义通道**：确认 Tavily Key 有效且有配额  
- **R3 地图发现**：确认已配置 [Places API Key](/docs/places-api-key)，且本机网络合法合规、可访问 Google 服务  
- 确认关键词扩展已生成；社媒发现还需要带站点的关键词  
- 探索需要一定时间；完成后到线索页刷新查看（线索页也可直接开始探索）

<h2 id="model-provider">官方通道和自定义通道有什么区别？</h2>

外贸获客（FTCS）需要大模型完成画像分析、关键词扩展、线索探索与开发信起草等推理。你可以二选一：

- **官方通道（推荐）**：经公司 Token 网关调用官方模型，费用从账户余额扣除；**无需自备上游模型 API Key**。搜索服务由官方通道免费提供，也**无需**再配置 Tavily Key。使用前需登录用户中心并开通官方通道。
- **自定义**：填写你自己的 OpenAI 兼容接口（含自备 DeepSeek 等）的 API Key、Base URL 与模型 ID；请求**不经过**公司网关计费。搜索需自备 [Tavily](https://tavily.com/) Key，直连 Tavily，不扣官方余额。

关系可以简单理解为：

- **本应用**：提供外贸获客流程、本地工作区、技能与界面；密钥与业务数据保存在你本机  
- **官方通道**：模型按余额计费；搜索免费提供；可在设置页充值，并在用户面板查看消费 / 充值 / 价格  
- **自定义通道**：你自备上游模型 Key 与 Tavily Key，按各服务商账单计费  

密钥（自定义 Key、网关凭证）只写在本机 `workspace/.env`，不会上传到 FTCS 官网。

## 官方通道如何充值与查看用量？

- **充值**：设置页官方通道区域可打开微信扫码充值页  
- **详情**：通过「账户详情 / 用户面板」查看余额相关信息、消费记录、充值入账、价格说明与 API Token  

余额不足时，模型或计费类能力可能提示不足；请先充值后再试。

## 可以用 Word / Excel 生成画像吗？

可以。`.docx` / `.xlsx` / `.pptx` 会在生成前抽成文本（原件仍保留在资料库）。可在首次引导或生成提示中**一键安装 OfficeCLI**（装到应用目录，不进入主安装包）。未安装时仍可用官网和 txt/md 等文本生成。

当前**不支持**：PDF、老格式 `.doc`、图片 OCR。详见 [安装与前置 · OfficeCLI](/docs/install#officecli)。

<h2 id="tavily-search">什么是 Tavily？还要配置搜索 Key 吗？</h2>

广撒网和社媒发现都需要联网检索公开内容。底层可使用 **Tavily** 等搜索能力。社媒发现会把检索限制在你启用的站点，不会打开社媒登录页。

- **官方通道**：**不需要**你配置 Tavily Key。开通官方通道后即可搜索，由官方免费提供。  
- **自定义通道**：需要自备 Tavily API Key（直连 Tavily，不经官方余额）。免费用户每月约有 1000 次调用配额（以 [Tavily 官网](https://tavily.com/) 当前说明为准）。在桌面端「设置 → 搜索服务」或首次引导中粘贴 Key。  

官方通道用户可直接开始探索；自定义通道用户可先完成产品画像与关键词扩展，开始探索前再补搜索 Key。

<h2 id="places-api-key">R3 地图发现需要 Places API Key 吗？</h2>

**R1 广撒网 / R2 社媒发现** 不需要。**R3 地图发现** 需要你在 [Google Cloud Console](https://console.cloud.google.com/apis/credentials) 自行申请 **Google Places API Key**，并启用 **Places API (New)**；费用计入你的 GCP 账号。

- **官方通道与自定义通道均需自备 Places Key**（模型 / Tavily 搜索与 Places 独立；FTCS 不提供 Google 代调）。  
- Key 填在桌面端 **设置 → 探索**，或首次引导 **步骤 2** 底部可选区块；保存后请 **重启 OpenCode**。  
- 请求由 **本机** 直连 Google 服务，你须在 **合法合规、可访问 Google 服务** 的网络环境中使用，并遵守当地法规与 [Places API 政策](https://developers.google.com/maps/documentation/places/web-service/policies)。

逐步申请说明见 **[申请 Places API Key](/docs/places-api-key)**。

## 邮件页没有草稿

- 仅 **已评分** 且通常为 **high** 的线索会批量起草  
- 可在线索页对单条线索点「写邮件」  
- 起草依赖 Agent 任务完成，请勿在任务进行中重复点击  

## 下载按钮不可用

下载镜像暂未公布或链路不可用时，按钮会停用。请稍后重试，或通过页脚电话 / 邮箱联系我们获取安装包。

## 数据存在哪里？安全吗？

业务数据与密钥保存在本机工作区（默认用户数据目录）。官网是纯静态站，不接收也不存储你的业务数据。

## 需要 Cursor 才能用吗？

不需要。业务用户通过 Electron 桌面应用操作即可；Cursor 主要用于开发与维护仓库。
