# 常见问题

## 标题栏一直显示未就绪 / 启动失败

- 确认 `node -v` 为 **v22 及以上**，且 `opencode --version` 可用  
- 检查是否被安全软件拦截本机端口（默认 OpenCode 端口可参考桌面端文档）  
- 在设置中查看 OpenCode 日志  

## 画像 / 探索时报浏览器或 chrome-devtools 相关错误

- 确认已安装 **Google Chrome** 且能手动打开  
- Electron 自带界面浏览器不能代替本机 Chrome  
- 重启应用后再试；必要时更新 Chrome 到较新版本  

## 探索没有线索

- 确认 Tavily（或配置的搜索）Key 有效且有配额  
- 确认关键词扩展已生成 `search_queries`  
- R1 需要一定时间；完成后到线索页刷新查看  

## 邮件页没有草稿

- 仅 **已评分** 且通常为 **high** 的线索会批量起草  
- 可在线索页对单条线索点「写邮件」  
- 起草依赖 Agent 任务完成，请勿在任务进行中重复点击  

## 下载按钮是灰色的

官网下载链接写在配置文件中，尚未填写时按钮会禁用并提示「链接待配置」。请等待官方公布地址，或联系维护者更新配置。

## 数据存在哪里？安全吗？

业务数据与密钥保存在本机工作区（默认用户数据目录）。官网是纯静态站，不接收也不存储你的业务数据。

## 需要 Cursor 才能用吗？

不需要。业务用户通过 Electron 桌面应用操作即可；Cursor 主要用于开发与维护仓库。
