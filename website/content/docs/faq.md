# 常见问题

## 标题栏一直显示未就绪 / 启动失败

- 确认 `node -v` 为 **v22 及以上**，且 `opencode --version` 可用  
- 检查是否被安全软件拦截本机端口（默认 OpenCode 端口可参考桌面端文档）  
- 在设置中查看 OpenCode 日志  

## 画像 / 探索时报浏览器或 chrome-devtools 相关错误

- 确认已安装 **Google Chrome** 且能手动打开  
- Electron 自带界面浏览器不能代替本机 Chrome  
- 重启应用后再试；必要时更新 Chrome 到较新版本  

<h2 id="model-provider">官方通道和自定义通道有什么区别？</h2>

外贸获客（FTCS）需要大模型完成画像分析、关键词扩展、线索探索与开发信起草等推理。你可以二选一：

- **官方通道（推荐）**：经公司 Token 网关调用 DeepSeek，费用从你的账户余额扣除；**无需自备上游 API Key**。使用前需登录用户中心并开通官方通道。
- **自定义**：填写你自己的 OpenAI 兼容接口（含自备 DeepSeek 等）的 API Key、Base URL 与模型 ID；请求**不经过**公司网关计费。

关系可以简单理解为：

- **本应用**：提供外贸获客流程、本地工作区、技能与界面；密钥与业务数据保存在你本机  
- **官方通道**：由公司网关代扣余额，统一提供可用模型  
- **自定义通道**：你自备上游 Key，按上游账单计费  

密钥（自定义 Key、网关凭证）只写在本机 `workspace/.env`，不会上传到 FTCS 官网。

## 探索没有线索

- 确认 Tavily（或配置的搜索）Key 有效且有配额  
- 确认关键词扩展已生成 `search_queries`  
- R1 需要一定时间；完成后到线索页刷新查看  

<h2 id="tavily-search">什么是 Tavily？为什么要配置搜索 API Key？</h2>

线索探索（R1）需要在公开网页中检索潜在客户。本应用通过 **Tavily** 这类搜索 API 来完成联网检索，而不是让你在浏览器里手工搜。

- **为什么需要单独 Key**：搜索调用由 Tavily 计费/计量；本应用不内置搜索额度，也不转发你的 Key  
- **免费额度**：Tavily **免费用户每月约有 1000 次调用配额**（以官网当前说明为准），对试用与小规模获客通常够用  
- **如何获取**：打开 [Tavily 官网](https://tavily.com/) 注册账号，在控制台创建 API Key，再粘贴到桌面端「设置 → 搜索服务」或首次引导的搜索栏中  

没有搜索 Key 时，仍可先完成产品画像与关键词扩展；开始探索前再补即可。

## 邮件页没有草稿

- 仅 **已评分** 且通常为 **high** 的线索会批量起草  
- 可在线索页对单条线索点「写邮件」  
- 起草依赖 Agent 任务完成，请勿在任务进行中重复点击  

## 下载按钮是灰色的

官网下载链接写在配置文件中，尚未填写时按钮会禁用并提示「链接待配置」。请等待官方公布地址，或联系维护者更新配置。

## 数据存在哪里？安全吗？

业务数据与密钥保存在本机工作区（默认用户数据目录）。官网是纯静态站，不接收也不存储你的业务数据。

## 需要 Cursor 才能用吗？

不需要。业务用户通过 Electron 桌面应用操作即可；Cursor 主要用于开发与维护仓库。
