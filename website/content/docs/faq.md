# 常见问题

<h2 id="what-is-ftcs">FTCS / 外贸获客智能体是什么？</h2>

FTCS 是 AI-Utills 旗下的 Windows 桌面外贸获客智能体（Agent）。在本机把产品资料变成画像、公开网页线索和可改稿开发信。产品站：[ftcs.ai-utills.com](https://ftcs.ai-utills.com/)。品牌站：[ai-utills.com](https://ai-utills.com/)。

<h2 id="vs-customs-linkedin">外贸获客系统和海关数据、领英开发有什么不同？</h2>

海关数据给你进口记录，领英销售工具帮你找联系人。FTCS 从你的产品画像出发，在公开网页广撒网，也可按领英、脸书等公开主页的搜索摘要发现公司并核对官网，再写出可改稿的开发信。不登录社媒、不代替领英开发——获客闭环留在本机。

<h2 id="data-and-send">数据会上传到官网吗？现在能直接发开发信吗？</h2>

工作区资料与配置保存在本机。执行 AI 分析、搜索等任务时，会调用你选择的模型及联网服务；本地保存不代表全程离线。开发信先生成可改稿草稿，你确认后再用，发出节奏由你掌握，避免误触达客户。

## 使用排障

## 标题栏一直显示未就绪 / 启动失败

- 确认 `node -v` 为 **v22 及以上**，且标题栏为 **服务已就绪**（应用内一键安装，或本机 `opencode --version` 可用）  
- 检查是否被安全软件拦截本机服务  
- 在 **设置 → 运行状态** 查看诊断信息  

## 画像 / 探索时内置浏览器报错

- 在环境检测里看「内置浏览器」是否就绪，未就绪则点「重新检测」
- 仍失败则重启应用
- 人机验证或登录墙仍停下，不要绕过
- 社媒发现不打开社媒真页  

## 全网搜索和社媒发现有什么不同？

探索页（以及线索页）可以分开开始：

- **全网搜索**：按关键词检索公开网页，并打开候选公司官网后写入线索。  
- **社媒发现**：只检索你在设置里启用的站点（默认 LinkedIn 公司页、Facebook 公共主页）的公开搜索摘要，抽出公司并核对官网后再写入。**不会登录、也不会打开领英 / 脸书真页。**  
- **地图发现**（可选）：用 Google Places 按城市与品类找本地商户。官方通道申请官方 Places Key；自定义通道须自备 Places API Key。  

在 **设置 → 探索** 可选择低 / 中 / 高探索强度（默认中）。强度越高，关键词和每次看到的结果越多。改强度或社媒站点开关后，需要重新扩展关键词。几种探索不共用同一次任务，可分开跑。

## 主题、完成通知和定时任务

- **设置 → 外观**：暗黑、日间或跟随 Windows 系统外观，切换后立即生效。标题栏按钮在当前画面的日间和暗黑之间一键切换。  
- **任务完成通知**默认开启：探索、评分、开发信等长任务结束，且窗口不在前台时弹出 Windows 通知。任务在等你回复、窗口不在前台时，也会弹出「任务在等你回复」。编排一键跑通只在整段结束时通知一次。可在设置中关闭。  
- **定时**：线索页对已保存方案按每日或每周时刻自动执行，最多 5 条。请开启开机自启，并让关闭窗口进入托盘。已有任务在进行时，本轮定时会跳过。

## 探索没有线索

- **官方通道**：确认已开通官方通道且运行状态正常（全网搜索、社媒发现无需单独的搜索 Key）  
- **自定义通道**：确认 Tavily Key 有效且有配额  
- **地图发现**：官方通道确认已申请官方 Places Key；自定义通道确认已配置 [Places API Key](/docs/places-api-key)。需要能访问 Google 的网络  
- 确认关键词扩展已生成；社媒发现还需要带站点的关键词  
- 探索需要一定时间；完成后到线索页刷新查看（线索页也可直接开始探索）

<h2 id="model-provider">官方通道和自定义通道有什么区别？</h2>

外贸获客（FTCS）需要大模型完成画像分析、关键词扩展、线索探索与开发信起草等推理。你可以二选一：

- **官方通道（推荐）**：经公司 Token 网关调用官方模型，费用从账户余额扣除；**无需自备上游模型 API Key**。搜索同样从账户余额扣除，也**无需**再配置 Tavily Key。使用前需登录用户中心并开通官方通道。
- **自定义**：填写你自己的 OpenAI 兼容接口（含自备 DeepSeek 等）的 API Key、Base URL 与模型 ID；请求**不经过**公司网关计费。搜索需自备 [Tavily](https://tavily.com/) Key，直连 Tavily，不扣官方余额。

关系可以简单理解为：

- **本应用**：提供外贸获客流程、本地工作区、技能与界面；密钥与业务数据保存在你本机  
- **官方通道**：模型与搜索均按余额计费；可在设置页充值，并在用户面板查看各模型价格、消费明细与充值记录  
- **自定义通道**：你自备上游模型 Key 与 Tavily Key，按各服务商账单计费  

密钥（自定义 Key、网关凭证）只写在本机 `workspace/.env`，不会上传到 FTCS 官网。

## 官方通道如何充值与查看用量？

- **充值**：设置页官方通道区域可打开微信扫码充值页  
- **详情**：通过「账户详情 / 用户面板」查看余额相关信息、消费记录、充值入账、价格说明与 API Token  

余额不足时，模型或计费类能力可能提示不足；请先充值后再试。

## 可以用 Word / Excel 生成画像吗？

可以。`.docx` / `.xlsx` / `.pptx` 会在生成前抽成文本（原件仍保留在资料库）。可在首次引导或生成提示中**一键安装 OfficeCLI**（装到应用目录，不进入主安装包）。未安装时仍可用官网和 txt/md 等文本生成。

当前**不支持**：扫描型 PDF、老格式 `.doc`。文字型 PDF 与资料树图片已支持（官方通道请选带读图能力的模型）。详见 [安装与前置 · OfficeCLI](/docs/install#officecli)。

<h2 id="tavily-search">什么是 Tavily？还要配置搜索 Key 吗？</h2>

全网搜索和社媒发现都需要联网检索公开内容。底层可使用 **Tavily** 等搜索能力。社媒发现会把检索限制在你启用的站点，不会打开社媒登录页。

- **官方通道**：**不需要**你配置 Tavily Key。开通官方通道后即可搜索，费用从账户余额扣除。  
- **自定义通道**：需要自备 Tavily API Key（直连 Tavily，不经官方余额）。免费用户每月约有 1000 次调用配额（以 [Tavily 官网](https://tavily.com/) 当前说明为准）。在桌面端「设置 → 搜索服务」或首次引导中粘贴 Key。  

官方通道用户可直接开始探索；自定义通道用户可先完成产品画像与关键词扩展，开始探索前再补搜索 Key。

<h2 id="places-api-key">地图发现需要 Places API Key 吗？</h2>

**全网搜索 / 社媒发现** 不需要。**地图发现** 需要 Places Key，按模型通道区分：

- **官方通道**：在桌面端 **设置 → 探索**（或首次引导第 2 步）申请官方 Places Key。申请受理后，预计在下一自然日内开通；设置里会显示开通状态。需要能访问 Google 的网络，地图发现由本机直接访问 Google；使用费用计入官方额度。欠费时会提示充值，已吊销时会提示联系客服。  
- **自定义通道**：在 [Google Cloud Console](https://console.cloud.google.com/apis/credentials) 自行申请 **Google Places API Key**，并启用 **Places API (New)**，填到 **设置 → 探索** 的自备 Places Key。费用由 Google 按其价格收取。保存后重启应用生效。  

请求由本机访问 Google 服务，并遵守 [Places API 政策](https://developers.google.com/maps/documentation/places/web-service/policies)。逐步申请自备 Key 的说明见 **[申请 Places API Key](/docs/places-api-key)**。

<h2 id="hunter-api-key">补全联系人需要 Hunter API Key 吗？</h2>

**可选。** 未配置时，画像、探索、评分与开发信主路径照常可用；线索页「补全联系人」会置灰并引导去设置。

- Key 在 [Hunter API Keys](https://hunter.io/api-keys) 创建，填入桌面端 **设置 → 集成 → Hunter**；费用计入你的 Hunter 账号。  
- 可勾选是否在补全时 **验证邮箱**（默认开启）；也可对单条联系人单独验证。  
- 同一 Hunter 账号下多个 Key **共享额度**，请只配置本人/团队合法持有的 Key。  

逐步说明见 **[申请 Hunter API Key](/docs/hunter-api-key)**。

## 开发信怎么审？还能选短函 / 正式函吗？

当前不再提供「短函 / 正式函」双变体。改为：

- 每条线索一封 **公司向**稿，并为有个人邮箱的联系人各起草一封；邮件页顶部切换收件人审阅  
- 在 **设置 → 开发信行文风格** 用自然语言描述语气（如「简洁、少套话」），影响之后的起草与重写  
- 可展开 **中文对照** 辅助理解原文；外发仍用外文稿  
- 需要对照公司信息时，点 **查看线索** 跳回线索页  

## 邮件页没有草稿

- 仅 **已评分** 且通常为 **high** 的线索会批量起草  
- 可在线索页对单条线索点「写邮件」；缺某一收件人的稿时可在邮件页单人补起草  
- 起草依赖 Agent 任务完成，请勿在任务进行中重复点击  

## 下载按钮不可用

下载镜像暂未公布或链路不可用时，按钮会停用。请稍后重试，或通过页脚电话 / 邮箱联系我们获取安装包。

## 数据存在哪里？安全吗？

工作区资料与配置保存在本机。执行 AI 分析、搜索等任务时，会调用你选择的模型及联网服务；本地保存不代表全程离线。官网展示站与执行任务所用的业务服务是不同环节。

## 需要 Cursor 才能用吗？

不需要。业务用户通过 Electron 桌面应用操作即可；Cursor 主要用于开发与维护仓库。
