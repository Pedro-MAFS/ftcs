# 推荐使用流程

桌面端流水线与侧栏模块一致，建议按顺序推进。

## 1. 产品录入

在 **录入** 页添加公司网站或普通文本类资料，归档到资料库。特殊格式（PDF / Excel 等）当前可能提示暂不支持。

## 2. 产品画像

触发画像生成后，在 **画像** 页核对公司、产品、买家画像与目标市场。画像是后续关键词与探索的基础，缺字段时可人工补全。

## 3. 关键词与探索

在画像就绪后扩展五维关键词，再在 **探索** 页启动 R1（广撒网）。可观察任务进度与已执行查询数。

## 4. 线索库

探索产物进入 **线索** 页：

- 未评分线索可人工编辑  
- 执行 **评分去重** 后按 tier（A/B/C）筛选  
- 对 high 线索 **写邮件**；已有草稿可点 **邮件** 跳转  

## 5. 邮件审核

在 **邮件** 页：

- 切换 short / professional 变体并直接改稿  
- **通过并保存**：落盘并标记线索为已通过（不发送）  
- **驳回**：删除草稿并将线索状态回退  

发送能力属于后续版本，当前以审核定稿为主。

## 建议节奏

先用少量搜索词跑通 R1 → 评分 → 1～2 封开发信，确认画像与话术质量，再扩大探索规模。
