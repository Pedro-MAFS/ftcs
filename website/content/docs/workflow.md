# 推荐使用流程

FTCS 外贸获客标准路径与桌面端侧栏一致，建议按顺序推进：**录入 → 画像 → 探索 → 评分 → 开发信**。

## 1. 产品录入

在 **录入** 页按自己的习惯建目录（例如「客户公司 / 地板」），把官网和说明书放在同一夹里：

- **网站**：在当前文件夹保存官网书签，不再是全局单独一列  
- **文件**：上传或拖入 txt / md 等文本，以及 Word / Excel / PPT（`.docx` / `.xlsx` / `.pptx`）  
- **生成画像**：勾选文件、书签，或直接勾选整个产品文件夹（默认只含该层内容）后生成一份画像  

官网与文件可同时选，信息会合并进同一份画像。PDF、老格式 `.doc` 以及图片 OCR 暂不支持；Office 文件需可选安装 [OfficeCLI](/docs/install#officecli)（未安装时仍可用官网和文本生成）。

## 2. 产品画像

触发画像生成后，在 **画像** 页核对公司、产品、买家画像与目标市场。画像是后续关键词与获客探索的基础，缺字段时可人工补全。

## 3. 关键词与获客探索

在画像就绪后扩展关键词（产品、场景、买家、地理等）。若要用社媒发现，请先在 **设置** 里确认已启用对应站点（默认 LinkedIn 公司页、Facebook 公共主页），再扩展关键词；改开关后需重新扩展。

然后在 **探索** 页（或 **线索** 页）选择方式并点「开始探索」：

- **广撒网**（界面选项 R1）：按关键词在公开网页检索，打开候选公司官网后，判断是否写入线索。  
- **社媒发现**（界面选项 R2）：只检索已启用站点的**公开搜索摘要**，从中抽出公司并核对官网后再写入线索。**不会打开领英 / 脸书登录页**，也不代替领英开发。  
- **地图发现**（界面选项 R3，可选）：用 Google Places 按城市与品类找本地商户，补全官网并核对后写入线索。**须自备 [Places API Key](/docs/places-api-key)**，且本机网络 **合法合规、可访问 Google 服务**。

探索页可填写「最多词数」限制规模。右侧时间线可展开查看智能体过程。若页面出现人机验证或登录墙，任务会停下，请不要尝试绕过。

## 4. 线索库

探索产物进入 **线索** 页：

- 未评分线索可人工编辑；匹配理由会标出广撒网或社媒发现  
- 执行 **评分去重** 后按 tier（A/B/C）筛选  
- 对 high 线索 **写邮件**；已有草稿可点 **邮件** 跳转  
- 本页也可直接开始下一轮探索  

## 5. 开发信草稿审核

在 **邮件** 页：

- 切换短函 / 正式函变体并直接改稿  
- **通过并保存**：定稿落盘，发出节奏由你掌握  
- **驳回**：删除草稿并将线索状态回退  

先把信写对、存好，再按你自己的方式发出。

## 建议节奏

先用少量搜索词跑通一次「广撒网 → 评分 → 1～2 封开发信草稿」，确认画像与话术质量，再扩大规模或补做社媒发现。

## 通道与搜索提示

- 使用 **官方通道** 时，开通后即可探索 R1/R2，无需再配置搜索 Key。  
- 使用 **自定义通道** 时，请先在设置中填好模型与 Tavily Key，再启动探索。  
- 若要 **R3 地图发现**，无论哪种通道都需自备 [Google Places API Key](/docs/places-api-key)，并在 **合法合规、可访问 Google 服务** 的网络环境下使用。
