# 推荐使用流程

FTCS 外贸获客标准路径与桌面端侧栏一致，建议按顺序推进：**录入 → 画像 → 探索 → 评分 → 开发信**。补全联系人（Hunter）为可选扩展，穿插在线索与开发信之间。

## 1. 产品录入

在 **录入** 页按自己的习惯建目录（例如「客户公司 / 地板」），把官网和说明书放在同一夹里：

- **网站**：在当前文件夹保存官网书签，不再是全局单独一列  
- **文件**：上传或拖入 txt / md 等文本，Word / Excel / PPT（`.docx` / `.xlsx` / `.pptx`），**图片**（jpg / png 等），以及 **文字型 PDF**（自动抽文本后进画像；扫描件暂不支持）  
- **生成画像**：勾选文件、书签，或直接勾选整个产品文件夹（默认只含该层内容）后生成一份画像  

官网与文件可同时选，信息会合并进同一份画像。勾选含图片时，请使用 **支持读图的模型**（官方通道部分模型已支持）。老格式 `.doc` 与扫描型 PDF 暂不支持；Office 文件需可选安装 [OfficeCLI](/docs/install#officecli)（未安装时仍可用官网、文本与图片生成）。

## 2. 产品画像

触发画像生成后，在 **画像** 页核对公司、产品、买家画像与目标市场。画像是后续关键词与获客探索的基础，缺字段时可人工补全。

## 3. 关键词与获客探索

在画像就绪后扩展关键词（产品、场景、买家、地理等）。在 **设置 → 探索** 选择探索强度（低 / 中 / 高，默认中）：更高会多出关键词，每次搜索和地图发现也会多看结果，耗时和费用更高。改强度后请重新扩展，已有关键词不会自动重算。若要用社媒发现，请先确认已启用对应站点（默认 LinkedIn 公司页、Facebook 公共主页），再扩展关键词；改开关后同样需重新扩展。

然后在 **探索** 页（或 **线索** 页）选择方式并点「开始探索」：

- **广撒网**（界面选项 R1）：按关键词在公开网页检索，打开候选公司官网后，判断是否写入线索。  
- **社媒发现**（界面选项 R2）：只检索已启用站点的**公开搜索摘要**，从中抽出公司并核对官网后再写入线索。**不会打开领英 / 脸书登录页**，也不代替领英开发。  
- **地图发现**（界面选项 R3，可选）：用 Google Places 按城市与品类找本地商户，补全官网并核对后写入线索。**须自备 [Places API Key](/docs/places-api-key)**，且本机网络 **合法合规、可访问 Google 服务**。

开始后会跑完该轮已经生成的合格词。右侧时间线可展开查看智能体过程。若页面出现人机验证或登录墙，任务会停下，请不要尝试绕过。

## 4. 线索库

探索产物进入 **线索** 页：

- 未评分线索可人工编辑；匹配理由会标出广撒网或社媒发现  
- 执行 **评分去重** 后按 tier（A/B/C）筛选  
- 对已评分线索可点 **补全联系人**（可选）：按官网域名用 [Hunter](/docs/hunter-api-key) 查找相关联系人，并按设置决定是否验邮；未配置 Hunter Key 时按钮不可用，**不影响**探索与开发信主路径  
- 对 high 线索 **写邮件**；已有草稿可点 **邮件** 跳转  
- 本页可选 **任务方案**，把探索、评分、起草等步骤 **按顺序一键跑通**（也可保留单步按钮）  
- 可为方案设置 **每日或每周定时**（最多 5 条）。请在设置中开启开机自启，并把关闭窗口改为进入托盘；到点若已有任务在跑会跳过  
- 本页也可直接开始下一轮探索  

## 5. 开发信草稿审核

在 **邮件** 页：

- 每条线索默认有一封 **公司向**草稿，并为有个人邮箱的联系人各起草一封（1+N）；顶部可切换收件人审阅，缺稿时可单人补起草  
- **行文风格**在 **设置 → 开发信行文风格** 用自然语言描述（默认「专业，真诚」），影响之后的起草与重写，不自动改已有稿  
- 可展开 **中文对照** 辅助审阅（外发仍用原文）；外文改稿后对照可能过期，可按需重新生成  
- **查看线索**：一键回到线索页并选中当前公司，便于对照联系人后再改稿  
- **通过并保存** / **驳回**：按当前收件人或整条线索操作；发出节奏由你掌握  

先把信写对、存好，再按你自己的方式发出。

## 建议节奏

先用少量搜索词跑通一次「广撒网 → 评分 → 1～2 封开发信草稿」，确认画像与话术质量，再扩大规模或补做社媒发现。需要具名收件人时，再为高意向线索配置 Hunter 并补全联系人。

## 通道与搜索提示

- 使用 **官方通道** 时，开通后即可探索 R1/R2，无需再配置搜索 Key。  
- 使用 **自定义通道** 时，请先在设置中填好模型与 Tavily Key，再启动探索。  
- 若要 **R3 地图发现**，无论哪种通道都需自备 [Google Places API Key](/docs/places-api-key)，并在 **合法合规、可访问 Google 服务** 的网络环境下使用。  
- **补全联系人** 为可选扩展，须自备 [Hunter API Key](/docs/hunter-api-key)；与模型 / 搜索通道独立，费用计入你的 Hunter 账号。
