# 快速开始

用桌面应用完成一次「产品 → 线索 → 开发信」闭环，大约需要 10 分钟（不含长时间探索）。

## 1. 安装并启动

1. 确认本机已有 **Node.js 22+**、**Google Chrome**（见 [安装与前置](/docs/install)）。
2. 在官网 [下载页](/download) 获取 Windows 安装包或便携版（链接配置后可用）。
3. 本机安装 [OpenCode CLI](https://opencode.ai)（轻量包依赖本机 `opencode`，需先有 Node）。
4. 启动「外贸获客」，确认标题栏显示运行时就绪。

详细步骤见 [安装与前置](/docs/install)。

## 2. 填写密钥

打开 **设置**：

- 配置大模型 API Key（Anthropic / OpenAI / Google 等）
- 配置搜索用的 Tavily（或兼容）Key

密钥保存在本机工作区 `.env`，不会上传到官网。

## 3. 跑通主流程

1. **录入**：添加公司网站或产品资料  
2. **画像**：生成并核对产品画像  
3. **探索**：扩展关键词后启动 R1  
4. **线索**：评分去重，查看高意向客户  
5. **邮件**：为 high 线索起草开发信，改稿后「通过并保存」

推荐顺序见 [使用流程](/docs/workflow)。
