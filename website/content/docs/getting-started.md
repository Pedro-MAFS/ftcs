# 快速开始

FTCS 是跑在本机的外贸获客智能体。用桌面应用完成一次「产品 → 线索 → 开发信草稿」闭环即可开始使用。

## 1. 安装并启动

1. 在官网 [下载页](/download) 获取 Windows 安装包或便携版并启动应用。
2. 按首次引导 **一键准备** Node.js 与 OpenCode（或确认本机已安装合格版本），并安装 **Google Chrome**（见 [安装与前置](/docs/install)）。
3. 确认标题栏显示运行时就绪。

详细步骤见 [安装与前置](/docs/install)。

## 2. 开通官方通道（推荐）

打开 **设置 → 模型通道**（或首次引导第 2 步）：

- **官方通道（推荐）**：登录用户中心后点击开通。模型列表从网关同步（含 DeepSeek、GLM / Qwen 读图等）——**无需自备上游模型 Key，也无需单独配置搜索 Key**；模型按账户余额计费，可在充值页与用户面板查看各模型价格，搜索由官方通道免费提供。
- **自定义通道**：自备 OpenAI 兼容接口的 API Key、Base URL、模型 ID，以及 **Tavily** 搜索 Key（不经官方余额）。

余额不足时可在设置页打开充值；更完整的消费、充值、价格与 API Token 管理见用户面板（设置中的「账户详情」入口）。

配置保存在本机工作区，不会上传到官网。

## 3. 跑通主流程

1. **录入**：按目录整理公司/产品资料（官网书签 + 文件），勾选后生成画像  
2. **画像**：生成并核对产品画像  
3. **探索**：扩展关键词后选择广撒网或社媒发现（界面选项为 R1 / R2）  
4. **线索**：评分去重，查看高意向客户  
5. **邮件**：为 high 线索起草开发信，改稿后「通过并保存」，发出节奏由你掌握

推荐顺序见 [外贸获客标准路径](/docs/workflow)。
