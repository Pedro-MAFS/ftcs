# 快速开始

用桌面应用完成一次「产品 → 线索 → 开发信」闭环，大约需要 10 分钟（不含长时间探索）。

## 1. 安装并启动

1. 确认本机已有 **Node.js 22+**、**Google Chrome**（见 [安装与前置](/docs/install)）。
2. 在官网 [下载页](/download) 获取 Windows 安装包或便携版。
3. 本机安装 [OpenCode CLI](https://opencode.ai)（轻量包依赖本机 `opencode`；也可在应用内一键安装）。
4. 启动「外贸获客」，确认标题栏显示运行时就绪。

详细步骤见 [安装与前置](/docs/install)。

## 2. 开通官方通道（推荐）

打开 **设置 → 模型通道**（或首次引导第 2 步）：

- **官方通道（推荐）**：登录用户中心后点击开通。模型与搜索均走官方服务——**无需自备上游模型 Key，也无需单独配置搜索 Key**；模型按账户余额计费，搜索由官方通道免费提供。
- **自定义通道**：自备 OpenAI 兼容接口的 API Key、Base URL、模型 ID，以及 **Tavily** 搜索 Key（不经官方余额）。

余额不足时可在设置页打开充值；更完整的消费、充值、价格与 API Token 管理见用户面板（设置中的「账户详情」入口）。

配置保存在本机工作区 `.env`，不会上传到官网。

## 3. 跑通主流程

1. **录入**：按目录整理公司/产品资料（官网书签 + 文件），勾选后生成画像  
2. **画像**：生成并核对产品画像  
3. **探索**：扩展关键词后启动 R1  
4. **线索**：评分去重，查看高意向客户  
5. **邮件**：为 high 线索起草开发信，改稿后「通过并保存」

推荐顺序见 [使用流程](/docs/workflow)。
