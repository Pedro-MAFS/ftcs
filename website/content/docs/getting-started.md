# 快速开始

FTCS 是跑在本机的外贸获客智能体。用桌面应用完成一次「产品 → 线索 → 开发信草稿」闭环即可开始使用。

## 1. 安装并启动

1. 在官网 [下载页](/download) 获取 Windows 安装包或便携版并启动应用。
2. 按首次引导一键安装 Node.js 与智能体服务。打开网页使用内置浏览器，见 [安装与前置](/docs/install)。
3. 确认标题栏显示服务已就绪。

详细步骤见 [安装与前置](/docs/install)。

## 2. 开通官方通道（推荐）

打开 **设置 → 模型通道**（或首次引导第 2 步）：

- **官方通道（推荐）**：登录用户中心后点击开通。模型列表从网关同步（含 DeepSeek、GLM / Qwen 读图等）——**无需自备上游模型 Key，也无需单独配置搜索 Key**；模型与搜索均按账户余额计费，可在充值页与用户面板查看各模型价格。
- **自定义通道**：自备 OpenAI 兼容接口的 API Key、Base URL、模型 ID，以及 **Tavily** 搜索 Key（不经官方余额）。

余额不足时可在设置页打开充值；更完整的消费、充值、价格与 API Token 管理见用户面板（设置中的「账户详情」入口）。

配置保存在本机工作区，不会上传到官网。

## 3. 跑通主流程

1. **录入**：按目录整理公司/产品资料（官网书签 + 文件），勾选后生成画像  
2. **画像**：生成并核对产品画像  
3. **探索**：在设置中选择探索强度后扩展关键词，再选择全网搜索、社媒发现或地图发现  
4. **线索**：评分去重，查看高意向客户。新线索会带上目标公司画像和可改的破冰话术。探索保存线索时，若该公司域名已在本产品线索库中，会跳过并保留旧线索。可选配置 [Hunter](/docs/hunter-api-key) 后 **补全联系人**  
5. **邮件**：为 high 线索起草开发信（公司向 + 个人收件人），按收件人改稿；需要时可生成中文对照。确认后「通过并保存」，发出节奏由你掌握  

在 **设置 → 外观** 可切换暗黑、日间或跟随系统；标题栏也能一键在日间和暗黑之间切换。任务在等你回复时，界面会显示题目和选项（默认允许自己填写），点选或填写后任务继续；较久不答会按默认项继续。长任务结束，或任务在等你回复且窗口不在前台时，会弹出 Windows 通知（等待回复的文案是「任务在等你回复」）。可在设置中关闭「任务完成通知」。线索页的任务方案还可以按每日或每周定时执行。

推荐顺序见 [外贸获客标准路径](/docs/workflow)。
