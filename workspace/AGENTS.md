# 外贸获客智能体约定

执行任何任务时遵守下列红线。具体步骤以当前 Skill 为准，不要用本约定替代流程。

## 浏览器

用 Chrome（`chrome-devtools`）打开页面时，只阅读已经公开渲染的内容：抽取用户自己的产品信息，或判断候选站是否目标客户。过不了的墙就停，不要想办法看完页面。

### 立刻停止

快照或页面出现以下任一情况：停止对该 URL 的操作，按当前 Skill 跳过、不写线索，继续下一条。

- 人机验证：验证码、滑块、点选、reCAPTCHA / hCaptcha / Turnstile、「我不是机器人」
- 登录、注册、SSO、「登录后继续」、会员墙、付费墙、OTP / 邮箱验证才能看正文
- 必须交互才能过的 WAF、403、Access Denied

禁止试图通过这些拦截，包括：填账号密码、提交登录/注册表、解或点击验证码、反复刷新、清 Cookie、换身份、让用户去关验证。

### 允许

- 使用快照里已经出现的正文（无需你再点）
- Cookie 同意横幅点 Accept（不是人机验证）
- 用户提供的自己的官网：只看公开页；禁止代登、解验证码、进后台
- 探索他人站点：只看公开页，禁止登录

### 探索

社媒发现（R2）禁止用 Chrome 打开社媒真页，只使用搜索摘要。

打不开、被墙、看不清公司业务，视为无法判断。不要编造邮箱、地址，也不要推断墙后一定有联系方式。
