# start-from-chat

自由对话里要启动获客步骤时，只用这一张提问卡把必填交给用户。桌面在用户提交后自己调用现有入口。你不要自己跑步骤。

## 何时使用

用户在**没有任务正在执行**的自由对话里，要开始下列任一步：

- 扩展关键词
- 探索（全网搜索 / 社媒发现 / 地图发现）
- 评分去重
- 起草开发信（起草待处理线索）

即使用户已经说了产品和阶段，仍然发这张卡让用户确认。不要从原话猜阶段后直接开跑。

## 不要用这张卡

画像、录入资料、补联系人、单封重写、中文对照不从聊天启动。用户要做这些时，请他用左侧对应按钮，不要发这张提问卡，也不要调用下面的步骤技能。

## 执行

1. 调用 `lead-store.product_list`（已允许，不会出现授权卡）。
2. 返回的 `products` 为空：直接说明还没有产品，请先在左侧建产品或完成画像。**不要**发 `question`。
3. 有产品：发**一次** `question`，然后**立刻停止**。不要写文件，不要加载或执行步骤技能，不要调用 `ftcs-task`。

`question` 返回之后也停住。不要根据返回值继续探索、评分或写开发信。启动由桌面完成。

## 提问卡

一次 `question` 里交完所有题。每题 `custom: false`，不设 `multiple`。不要出现「输入自己的答案」。

| header | 何时必须有 | 选项 `label` | `description` |
|--------|------------|--------------|----------------|
| `产品` | 总是 | `product_list` 里的 `id` | `company_name`；没有就写「未命名」 |
| `阶段` | 总是 | `keywords` | 扩展关键词 |
| `阶段` | 总是 | `explore` | 探索 |
| `阶段` | 总是 | `score` | 评分去重 |
| `阶段` | 总是 | `email` | 起草待处理线索 |
| `渠道` | 阶段可能是探索时必须有。用户已经说清是扩展关键词、评分去重或起草时可以不问 | `r1` | 全网搜索 |
| `渠道` | 同上 | `r2` | 社媒发现 |
| `渠道` | 同上 | `r3` | 地图发现 |

`label` 必须是上表里的提交值（产品用 id，阶段用 `keywords` / `explore` / `score` / `email`，渠道用 `r1` / `r2` / `r3`）。说明写在 `description`，不要写进 `label`。

题头必须是上面这三个字，桌面靠题头接线。不要改成「产品 ID」「选择阶段」之类。

## 禁止

- 不要调用 `ftcs-task`，也不要调用 `start_task`
- 不要写文件，不要调用 `edit` / `bash`
- 不要在自由对话里执行 `expand-keywords`、`discover-leads`、`discover-leads-r2`、`discover-leads-r3`、`score-and-dedupe`、`draft-outreach-email`
- 不要发第二张启任务卡，也不要为同一件事再追问
